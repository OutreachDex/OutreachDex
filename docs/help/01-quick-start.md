# Quick start

OutreachDex helps you build one-to-one relationships with every person who matters: understand them, prepare a tailored message, send it after you review it, and keep following up. All data lives in a **workspace folder** on your computer; the first one is created for you.

## First use

1. **Your workspace**: on first launch OutreachDex creates one in **Documents → OutreachDex** (Blank template) and opens it, so you can start right away. For another template or folder, click the workspace name in the top-left → New workspace… or Open workspace…. Templates:
   - **Blank**: general stages, suitable for any one-to-one outreach.
   - **Expert outreach**: research, first contact and follow-up with academics or industry experts.
   - **Product user relationships**: understand your product users' goals and feedback, and follow up on issues.
2. **Add contacts**: on the **People** page click "New contact", or use "Import" to bring in a list from CSV / a spreadsheet (see [Import contacts](11-import.md)).
3. **Connect mail** (optional): in **Settings → Mail accounts**, add incoming (IMAP) and outgoing (SMTP) accounts. Incoming mail is filed under the matching contact automatically.
4. **Set up the Agent** (optional): analysis and drafting use the Claude Code or Codex you are already signed in to on this computer. Sign in to them in a terminal before first use. OutreachDex doesn't include either one: if neither is installed, the Agent pane and **Settings → Assistant** show the command to install it.

## Everyday use

- Open **Today**: see who is waiting for your reply, which drafts are waiting for review, and who needs a follow-up.
- Press **⌘ / Ctrl + K** to search for any person, list or draft; press Enter to open it.
- Open a person: see their profile, activity and source facts on the person page. Click "Ask Agent" and the Agent on the right sums up the situation; "Agent drafts reply" prepares a reply for your review.
- Edit a draft, **approve** it, then pick a sending account and **confirm the send**. OutreachDex never sends anything automatically.

## Layout

| Area | Purpose |
|---|---|
| Left navigation | Today, People, Lists, Mail, Sources, Settings |
| Center | The current page: a list, a person page, a document |
| Agent on the right | A command-line assistant docked on the right; ⌘ / Ctrl+J shows or hides it, drag its left edge to resize |

In **Settings → Appearance** you can choose the theme (Light / Dark / System) and the density (Comfortable / Compact).

The interface language can be switched in **Settings → Appearance → Interface language**: English / 中文 / 日本語 / 한국어.
