# Keyboard shortcuts

| Shortcut | Action |
|---|---|
| ⌘ / Ctrl + K | Global search: people, lists, drafts, pages and common actions (not intercepted inside the terminal) |
| ⌘ / Ctrl + J | Show / hide the Agent (also works inside the terminal) |
| ⌘ / Ctrl + S | Save the current document or draft |
| ⌘ / Ctrl + F | Search the record in the Agent terminal |
| ↑ ↓ / J K | Move in the **People** list; Enter to open |
| J / K | Go to the next / previous person on the person page |
| Esc | Close a dialog; return to the list from the person page |
| ← → / Home / End | Switch between section tabs on the person page |
| Tab / Shift + Tab | Move focus within a dialog (never leaves the dialog) |
