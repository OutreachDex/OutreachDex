# クイックスタート

OutreachDex は、大切な一人ひとりと一対一の関係を築くためのツールです。相手を理解し、相手に合わせたメッセージを用意し、あなたが確認してから送信し、フォローアップを続けます。すべてのデータは、あなたが選んだ**ワークスペースフォルダ**に保存されます。

## はじめて使うとき

1. **ワークスペースを作成**：左上のワークスペース名 → 新しいワークスペース… をクリックし、テンプレートを選んでから空のフォルダを選びます。
   - **空白**：汎用的なステージ。あらゆる一対一の連絡に。
   - **専門家への連絡**：研究者や業界の専門家の調査、初回連絡、フォローアップ。
   - **プロダクトユーザーとの関係**：プロダクトのユーザーの目的やフィードバックを理解し、問題対応をフォローアップ。
2. **連絡先を追加**：「人物」ページで「新しい連絡先」をクリックするか、「インポート」で CSV / 表からリストを取り込みます（[連絡先のインポート](11-import.md)を参照）。
3. **メールを接続**（任意）：「設定 → メールアカウント」で受信（IMAP）と送信（SMTP）のアカウントを追加します。受信メールは対応する連絡先に自動で振り分けられます。
4. **Agent を準備**（任意）：分析と下書きには、このコンピュータでサインイン済みの Claude Code または Codex を使います。初回はターミナルでサインインしてください。

## 普段の使い方

- 「**今日**」を開く：返信を待っている人、レビュー待ちの下書き、フォローアップが必要な人を確認します。
- **⌘ / Ctrl + K** で人物、リスト、下書きを検索し、Enter で開きます。
- 人物を開く：人物ページでプロフィール、やり取り、ソースの事実を確認します。「Agent に把握させる」をクリックすると右側の Agent が状況を整理し、「Agent が返信を下書き」でレビュー用の返信を用意します。
- 下書きを編集して**承認**し、送信アカウントを選んで**送信を確定**します。OutreachDex が自動で送信することはありません。

## 画面構成

| エリア | 役割 |
|---|---|
| 左のナビゲーション | 今日、人物、リスト、メール、ソース、設定 |
| 中央 | 現在のページ：リスト、人物ページ、ドキュメント |
| 右の Agent | 右側に固定されたコマンドラインアシスタント。⌘ / Ctrl+J で表示 / 非表示、左端をドラッグして幅を調整 |

「設定 → 外観」で、ライト / ダーク / システムに合わせる、および標準 / コンパクトの表示密度を切り替えられます。

インターフェースの言語は「設定 → 外観 → インターフェース言語」で切り替えられます：中文 / English / 日本語 / 한국어。
