# 人物と人物ページ

## 「人物」ページ

すべての連絡先が表で表示されます。

- **ビュー**：すべて、返信待ち（あなたの最後の送信より後に相手が返信）、フォローアップ（送信後、設定した日数を過ぎても返信がない）。
- **検索とフィルター**：名前、所属、メールで検索。ステージで絞り込み。
- **キーボード**：↑ ↓ または J / K で移動、Enter で開く。
- **一括操作**：複数人にチェックを入れると（見出しのチェックボックスで現在のリストを全選択）、ステージの一括変更、フォローアップの設定（明日 / 3 日後 / 1 週間後 / 1 か月後 / クリア）、CSV のエクスポートができます。
- **エクスポート**：「エクスポート」で現在のリストの全フィールドを CSV に書き出します（BOM 付きなので Excel でも文字化けしません）。
- **表の編集**：表エディタで、連絡先、チャネル、ソースの ID、やり取りのデータをまとめて整理できます。

## 人物ページ

左が内容、右がプロパティと連絡チャネルです。

| セクション | 内容 |
|---|---|
| 概要 | 次のステップ、ソースの事実、きっかけ、AI による背景の要約、Agent メモリ、注意事項、未処理の下書き、最近のやり取り |
| 下書き | この人のすべての下書き。チャネルで絞り込み可能 |
| やり取り | メール、記録した資料やフィードバック、ソースのイベント |
| 人物メモ | この人の Markdown の人物メモ。直接編集できます |

- **事実と推測は分けて表示**：「資料」「ソース」タグは記録された事実、「AI の推測」タグはアシスタントの判断です。使う前に確認してください。
- **連絡先の切り替え**：上部バーの ↑ ↓、またはキーボードの K / J で前 / 次の人へ。Esc でリストに戻ります。
- **ステージ**：右側のプロパティで変更します。メッセージを送ると自動で「送信済み」系のステージに、返信を受け取ると「返信あり」系のステージに変わります。ステージ名はワークスペースの設定で変更できます（[ワークスペースと設定](10-workspace.md)を参照）。

## プロフィール：カスタムフィールド

人物ページ右列の「プロフィール」には、この人のすべてのフィールドが表示されます。クリックして編集でき、**入力欄から離れると自動で保存されます**。

- **フィールドの追加**：電話、役職、誕生日、タグ、関係など、「フィールドを追加」で自由に追加できます。
  - 種類：テキスト、長いテキスト、数値、日付、リンク、はい / いいえ、単一選択、複数選択（タグ）。
  - 新しいフィールドはすべての連絡先に追加され、ワークスペースの連絡先の表に保存されます。
- **選択肢**：単一選択フィールドでは「＋ 新しい選択肢…」で追加できます。複数選択フィールドではカンマ区切りで入力すると、新しいタグが自動で選択肢に加わります。
- **アプリが管理するフィールド**：最終連絡 / 最終返信の日時、AI 要約、ID はアプリが管理するため、ここでは編集しません。
- **変更履歴**：右列下部の「変更履歴」に、各フィールドがいつ何から何に変わったかが一覧表示されます。

## 重複した連絡先の統合

同じ人に 2 件のレコードがある場合は、残したい方の人物ページで「統合…」をクリックし、もう一方のレコードを選びます。

- 統合前に、移される内容が表示されます：チャネル、やり取り、ソースの ID、下書き、記録した資料、補完される空のフィールド。
- 統合時：
  - チャネルは重複を除きます；
  - 空のフィールドはもう一方の値で補完し、既存の値はそのままです；
  - 最終連絡 / 最終返信の日時は新しい方を採用します；
  - 統合される側の人物メモの本文は末尾に追加されます。
- 統合されたレコードは削除され、元に戻せません（必要なら git やバックアップからワークスペースを復元してください）。承認済みの下書きは統合後に改めて承認が必要です。

## 資料とフィードバックの記録

人物ページで「資料 / フィードバックを記録」をクリックすると、Web の抜粋、SNS の投稿、ユーザーのフィードバックの原文、ヒアリングの結果などを貼り付け、出典を記録できます。「保存して Agent に分析させる」を選ぶと、右側の Agent がこの記録を踏まえて次のステップを分析します。

リンクだけを保存しても Web ページの内容は取得されません。原文を貼り付けてください。
