# 今日

「今日」は、あなたの対応が必要なことを優先度順に 1 画面にまとめます。

| グループ | 意味 |
|---|---|
| あなたの返信待ち | 相手が最近返信し、まだ返答していない |
| レビュー待ちの下書き | アシスタントまたはあなたが書いた、承認・送信を待つ下書き |
| 期限のフォローアップ | 予定したフォローアップ日になった、または送信後に設定日数を過ぎても返信がない（日数は「設定 → AI アシスタント → フォローアップのリマインダー」で変更） |
| 判断が必要 | データソースの確認待ちの ID 照合と、同期に失敗したソース |

どの行をクリックしても、該当する人物、セクション、下書きが直接開きます。統計の下にある「同期して要約」を押すと、右側の Agent が接続済みのメールボックスとデータソースを同期し、新しい動きがあった人を緊急度順にまとめます（まとめるだけで、下書きも送信もしません）。一時停止や「連絡しない」ステージの人は、返信待ちとフォローアップには表示されません。

## はじめにのチェックリスト

新しいワークスペースでは、「今日」の上部にチェックリストが表示されます：連絡先の追加、メールの接続、データソースの接続、AI アシスタントの準備。完了した項目には自動でチェックが付き、すべて完了するか「今後表示しない」をクリックすると非表示になります。

## フォローアップのリマインダー

各人に「次回のフォローアップ」日を設定できます。人物ページの「次のステップ」の下で設定します：

- 「明日」「3 日後」「1 週間後」をワンクリックで選ぶか、日付を選びます。「クリア」でリマインダーを解除します。
- **メッセージを送ると**（メール送信または送信済みにする）、「フォローアップのリマインダー」の日数後に自動で設定されます。
- **相手が返信すると**、リマインダーは自動で解除され、その人は「あなたの返信待ち」に表示されます。
- **不在の自動返信を受け取ると**、メールに書かれた戻り日（「11月10日」「November 10」など）の翌日に設定されます。日付が読み取れない場合は 1 週間後に設定されます。
- **定期的に連絡**：フォローアップ欄の右で頻度を選びます（毎週、2 週ごと、毎月、四半期ごと、半年ごと）。設定すると、メッセージ送信時にこの頻度で次回のフォローアップが設定されます。フォローアップが設定されておらず、最後のやり取りからこの頻度を超えた場合もリマインドされます。
- フォローアップ日になった人は「期限のフォローアップ」と「人物 → フォローアップ」に表示されます。
