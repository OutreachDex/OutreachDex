# 分析とプレイブック

すべての分析は右側の Agent（このコンピュータの Codex または Claude Code）が行います。左側には結果だけが表示されます：プロフィール、要約、次のステップ、「Agent メモリ」。

## Agent に人物を把握させる

1. 人物ページで「Agent に把握させる」をクリックするか、右側の Agent で「この人を把握」をクリックします。
2. 右側に、この人に固定された新しいセッションが開きます。Agent はまずこの人の **Agent メモリ**、人物メモ、やり取り、ソースの事実を読み、背景、最近の状況、ニーズ、次のステップをまとめます。
3. さらに質問したいときは、ターミナルに直接入力します。例：「前回話していたエクスポートの問題は解決した？」

Agent の回答は事実、推測、不明点を区別し、最後に次の 2 つのセクションで締めくくります：

- 「**根拠**」：主な結論ごとに出典（人物メモ、メール、ソースのイベント、URL）を付記；
- 「**要確認**」：出典のない主張と、相手に聞くべき質問。

必要に応じて、Agent は人物メモの分析セクション、背景の要約、次のステップを更新し、フォローアップ日を設定することもあります。

## 返信を下書き

「Agent が返信を下書き」をクリックします（人物ページ、やり取りの受信メールの横、または右側の「返信を下書き」）。Agent は最新の受信メールを確認し、相手の意向（興味あり、詳しい情報がほしい、今は都合が悪い…）を判断してから、**レビュー待ちの下書き**を保存します。承認と送信は常にあなたが行います。

## 分析結果の保存先

「この人を把握」の結論は、ターミナルに残すだけでなく保存されます。

- **人物ページの概要 →「Agent の分析」カード**：根拠・要確認を含む結論全文（表や出典リンクも正しく表示）、作成日時、根拠と要確認の件数。「セッションを見る」で当時のターミナル記録に戻り、「もう一度把握」で再分析します。新しい分析は前回を置き換え、以前の要点は Agent メモリに残ります。
- **背景の要約と次の一手**：一、二文の要約と提案される次の一手。
- **今日 →「Agent の最近の結果」**：各セッションの最新の結果（完了・返信待ち・進行不可）。クリックすると該当の人物とセッションを開きます。

## Agent メモリ：使うほど相手を理解する

各人には時系列で追記される「Agent メモリ」（ワークスペースの `memory/<連絡先>.md`）があり、人物ページの概要で確認できます：

- **事実**（出典付き）、**判断**、**好み**（相手が好む連絡方法）、**約束**（双方が約束したこと）、**要確認**；
- **操作ログ**：Agent が OutreachDex を通じて行ったすべての変更（プロフィールの更新、下書きの保存、フォローアップの設定…）。アプリが自動で記録します。

新しい分析は毎回まずこのメモリを読むので、相手への理解はゼロからやり直すのではなく積み重なっていきます。連絡先を統合すると、2 つのメモリもまとめられます。「全記録を開く」で全文を読めます。

Agent の権限：

- **できる**：データの読み取り、人物メモの分析セクションの更新、要約と次のステップの更新、フォローアップの設定、Agent メモリへの書き込み、**レビュー待ちの下書きの保存**。
- **できない**：メッセージの承認や送信。

## プレイブック：分析の目的とビジネス背景をカスタマイズ

分析の目的とビジネス背景は、ワークスペースの `playbooks/` フォルダにある Markdown ファイルです。編集も追加もできます。

```markdown
---
id: feedback
label: 处理反馈
kind: purpose        # purpose = 分析目的；context = 业务背景
order: 20
creates_drafts: false
requires_prompt: false
---
理解用户反馈：任务、现象、影响、已有证据、未知点，给出具体下一步。
```

- Agent は各セッションの開始時に `workspace.guide` ですべてのプレイブックを読みます。`kind: context` のファイルはビジネス背景です。たとえば `my-product.md` を作り、プロダクトとユーザー層を説明します。
- `creates_drafts: true` は、この目的でメッセージを下書きできることを意味します。
- プレイブックの内容にかかわらず、「送信しない、レビュー待ちの下書きだけを書く、事実と推測を区別する」という安全ルールはアプリが必ず適用します。
