# 下書き、レビュー、送信

送信は必ずあなたが行います：**編集 → 承認 → アカウントを選んで送信を確定**。

## 編集と承認

- 人物ページで「下書きを書く」をクリックするか、アシスタントが作成した下書きを開きます。
- **参考稿**を選んで並べて比較できます。たとえば 2 つのアシスタントがそれぞれ書いた場合などです。
- ダイアログを閉じたりページを切り替えたりすると、保存していない変更はこのセッション中は一時保持され、下書きに「一時保持された変更あり」と表示されます。一時保持は保存ではありません。アプリを終了する前に通知されます。
- 「保存して承認」をクリックすると、下書きは承認済みになります。**承認後に内容を変更した場合は、もう一度承認が必要です。**

## レビュー時のヒント

- **AI の原稿**：アシスタントが書いた下書きは原文を保持します。編集後、「参考稿」で「AI の原稿（編集前）」を選ぶと並べて比較できます。
- **古い可能性**：下書きの作成後に相手から再度メールが来た場合、下書きに「古い可能性」と表示されます。送信または送信済みにする前に「最新のメールを確認しました」にチェックを入れる必要があり、バックエンドでも再確認します。
- **文面チェック**：本文の下に、決まり文句の書き出し、AI っぽい語彙、長すぎる文、質問やリンクの多さ、感嘆符やダッシュの多さを表示します。ヒントのみで、自動では変更しません。
- **置き換えていないプレースホルダー**：`{{name}}` や `[姓名]` などはブロックされ、送信できません。

## アシスタントをあなたらしく

下書きのレビュー中に、本文の下の「**書き方の好みを覚える**」をクリックします。例：「冒頭のあいさつは省き、すぐに用件を書く」「中国語は 150 字以内」。

- 好みはワークスペースの `preferences.md` に保存されます；
- 以後の分析、下書き、リストの一括準備はすべて Agent のターミナルで行われ、すべてこの好みに従います；
- 「設定 → 書き方の好み」で確認、編集、削除できます。

## 宛先のチェック

メールの下書きの宛先は、その人の既知のアドレス（プロフィールのメール、連絡チャネルのメール、関連付けたソースのメール）である必要があります。打ち間違いや、Agent が一致しないアドレスを書いた場合は、宛先の下に黄色の注意と既知のアドレスが表示され、クリックで修正できます。新しいアドレスに送る場合は、送信前にもう一度確認します。

## 送信

- **メール**：承認済みのメールの下書きで送信アカウント（SMTP）を選び、「メールを送信」をクリックし、確認ダイアログでもう一度確定します。
- **その他のチャネル**（X、WeChat、Instagram など）：「本文をコピー」をクリックし、各プラットフォームで自分で送信してから戻って「送信済みにする」をクリックします。

送信前に、アプリは次の 3 点を必ず確認します。1 つでも満たさない場合は送信しません：

1. 宛先が「連絡しない」リスト（ワークスペースの `suppression.txt`）にない；
2. 連絡先のステージが「連絡しない」ではない；
3. リストからのメッセージが 1 日の上限を超えていない。

いったんすべて止めたいとき（バウンスが増えた、送信設定を確認したいなど）は、「設定 → AI アシスタント」で「**すべての送信を一時停止**」にチェックを入れます。メール送信も「送信済みにする」も拒否されますが、下書きの編集と承認はできます。上部バーには「送信を一時停止中」と表示され続けます。

送信中にネットワークが切れた場合、二重送信を防ぐため、下書きは「送信結果を確認してください」となりロックされます。メールボックスの送信済みフォルダで確認してください。
