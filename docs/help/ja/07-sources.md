# データソースの接続

データソースを使うと、業務バックエンド（プロダクトのユーザー管理画面やチケットシステムなど）から「人」と「イベント」を OutreachDex に渡せます。各人のプラン、利用状況、フィードバックを確認し、それに基づいて分析・連絡できます。

## バックエンドで必要なこと

バックエンドは **GCSP/1** 仕様に沿って 3 つの読み取り専用エンドポイント `/manifest`、`/people`、`/events` を実装し、読み取り専用のトークンを発行します。仕様の全文はプロジェクトの `docs/gcsp.md` にあり、Go と Node の参考実装もあります。開発者はまずコマンドラインでテストできます：

```sh
globalcontact source check https://你的后台/gcsp --token <token>
```

## 接続

1. 「ソース」ページ → ソースを接続 を開きます。
2. ソースの URL とトークンを入力します。ヘッダーの既定は `Authorization` で、バックエンドが別のヘッダーを使う場合のみ変更します。
3. 「チェック」をクリック：アプリが各エンドポイントを仕様に照らして確認し、最初の数人をプレビューします。
   - **失敗**の項目はバックエンドで修正が必要です；
   - **警告**の項目は接続できますが、後でバックエンドで修正することをおすすめします。
4. 「接続して同期」をクリック。以後は設定した間隔（既定 60 分）で自動的に差分同期され、いつでも「今すぐ同期」できます。

URL は `https://` である必要があります（ローカルでのテストには `http://127.0.0.1` を使えます）。トークンはこのコンピュータで暗号化して保存されます。OutreachDex は読み取り専用のエンドポイントだけを呼び出し、バックエンドには何も書き込みません。

## ID の照合

同期された各人は、次のルールで連絡先に対応付けられます：

| 状況 | 結果 |
|---|---|
| バックエンドで確認済みのメールがある連絡先と一致 | **自動で関連付け** |
| メールは一致するが、バックエンドで未確認 | 「**確認待ち**」に入り、同一人物かあなたが判断 |
| 一致なし | 「**未関連付け**」のまま。「連絡先として作成」または既存の連絡先に「関連付け…」できます |

- 同名というだけで自動的に統合されることはありません。
- 「別人」を選ぶと、再同期しても再び提案されません。
- 関連付け後、その人のソースのイベントがやり取りに追加され、ソースのメールが連絡チャネルに加わります。

## まだ連絡先でないユーザーを把握する

「ソース」ページで任意の人（未関連付けの人も含む）をクリックすると、ソースにある事実、属性の変化、イベントが表示され、イベントをクリックすると原文を開けます。「Agent に把握させる」をクリックすると、右側の Agent がこれらを読み、利用段階・支払い・抱えている問題・活動状況を要約し、今連絡する価値があるかを判断します。先に連絡先にする必要はありません。価値があれば「連絡先にする」から下書きを作ります。

Agent はすべてのソースユーザーを検索することもできます。例：「無料ユーザーのうち、クレジットを使い切ったのに最近も使っているのは誰？」

## ソースの事実

関連付けられた人については、人物ページの「ソースの事実」カードに、バックエンドが提供する属性（プラン、クレジット、登録日など）が、ソースと同期時刻とともに表示されます。バックエンドが個人情報として指定した属性には印が付きます。バックエンドの manifest で宣言された属性だけが保存されます。

## 変更履歴

同期のたびに OutreachDex はその人の属性を比較し、変化を記録します。例：「プラン：free → pro」「残りクレジット：20 → 0」。

- 人物ページの「ソースの事実」カードで「変更履歴」をクリックすると、最近の変化を確認できます。
- 完全な記録はワークスペースの `sources/<ソース>/people/<ID>.md` に保存されます。上部が現在の属性、下部が日時付きの変更ログです。直接開いて読むことも、Agent に分析させることもできます。
- バックエンドの manifest で宣言された属性だけが記録されます。

## 新しい連絡先の言語

ソースから作った連絡先には言語が設定され、Agent はその言語で下書きします。順序は、ソースが示すその人の言語 → ソースの「…」メニューの「新しい連絡先の言語」→ ソースが宣言した既定の言語 → ワークスペースの既定です。ThumbnailSnap のような英語サイトでは「新しい連絡先の言語」を English にしてください。下書きの言語が連絡先の言語と合わないときはレビュー画面で注意が表示されます。
