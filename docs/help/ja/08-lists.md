# リストとコールドアウトリーチ

リストは、連絡先とデータソースから**今連絡する価値のある人**を見つけるためのものです。アシスタントが一人ずつ調べて下書きし、あなたが一人ずつレビューします。送信するかどうかは常にあなたが決めます。**一斉送信も自動送信もしません**。

## リストの作成

「リスト」ページで ＋ をクリックし、次を入力します：

- **名前と目的**：目的は、なぜこの人たちに連絡するのかをアシスタントに伝えます。例：「どこでつまずいているか、助けが必要かを知る」。
- **候補の出どころ**：既存の連絡先、またはあるデータソースの人（まだ関連付けられていない人も含む）。
- **チャネル、分析の目的、ビジネス背景**。
- **絞り込み条件**（すべて満たす必要があります）：
  - ソースの属性：例 プラン = free、残りクレジット ≤ 0；
  - イベント：例 30 日以内に「クレジット切れ」があり、「クレジット購入」がない；
  - イベントの回数：例 14 日以内に「タスク失敗」が 2 回以上、「クレジット購入」がちょうど 0 回（日数を空欄にすると全期間）；
  - 連絡状況：ステージ、未連絡、最終連絡から N 日以上；
  - 連絡先のフィールド：例 プロジェクト、所属。

編集中は、条件に合う人数と最初の数人がリアルタイムで表示されます。「連絡しない」の人は自動で除外されます。リストはワークスペースの `lists/` フォルダに保存されます。

## 一括準備

何人かにチェックを入れるか、そのまま「一括準備」をクリックします。対象の人はキューに入り、右側の Agent が**一人ずつ**処理します（各ステップはターミナルに表示されます）：

1. ソースにいてまだ関連付けられていない人は、まず連絡先として作成します；
2. 選ばれた理由（ソースの事実とやり取り）を確認します；
3. 今連絡することが本当に相手のためになる場合、レビュー待ちのメッセージを下書きし、冒頭で今連絡する理由を説明します。情報が足りない場合は下書きせず、メンバー表に理由を書きます。

準備には、このコンピュータでサインインしている Claude Code / Codex を使い、あなたのモデルの利用枠を消費します。Agent が中断した場合は、リストの上の「Agent に続けさせる」で再開できます。「キューを取り消す」こともできます。各人が選ばれた理由はメンバー表に表示されます。

## 一人ずつレビュー

「一人ずつレビュー」をクリックします：

- 左に「今連絡する理由」とソースの事実、右に下書き。
- 操作：**保存**、**承認して次へ**、**スキップ**、**連絡しない**。
- 承認しても送信はされません。送信するときは、下書きで「送信へ…」をクリックし、送信アカウントを選んで確定します。

## 迷惑をかけないために

- **連絡しない**：アドレスがワークスペースの `suppression.txt` に書き込まれ、連絡先のステージが「連絡しない」に変わり、この下書きは破棄されます。以後、すべてのリストから除外され、送信も拒否されます。
- **1 日の上限**：リストのメッセージを 1 日に送れる最大数（既定 20。メール送信も手動の「送信済みにする」も数えます）。`globalcontact.toml` の `[outreach] daily_limit` で変更します。リストページの右上に今日送った数が表示されます。
