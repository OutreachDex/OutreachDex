# Agent ワークスペース

右側の Agent は本物のコマンドラインアシスタント（このコンピュータの Codex または Claude Code）で、OutreachDex のツールを通じて連絡先とドキュメントを読み書きします。

## 基本操作

- **表示 / 非表示**：⌘ / Ctrl+J、または上部バーの Agent をクリック。非表示にしてもセッションは動き続けます。
- **幅の調整**：左端をドラッグするか、区切り線にフォーカスして矢印キーを使います。ダブルクリックで既定に戻ります。

パネルは上から 3 つの部分だけです：

1. **ヘッダー**：緑の点はセッションが動いていることを示し、その横に現在のセッション名が表示されます。右側には「セッション一覧」「ワークスペースのドキュメント」「新しいセッション」「閉じる」が並びます。
2. **クイックタスク**：今見ている人を表示し、その下に 3 つのボタン——「この人を把握」「返信を下書き」「同期して要約」（接続済みのメールボックスとデータソースを同期し、新しい動きがあった人をまとめる）。どのボタンも新しいセッションを開きます。
3. **ターミナル**：Agent の各ステップがここに表示され、直接入力して質問を続けられます。「Enter ↵」で Enter キーを 1 回送ります。

- **セッション一覧**：以前のセッションへの切り替え、現在のセッションの名前変更、新しいセッションで Codex と Claude Code のどちらを使うかの選択。
- **ワークスペースのドキュメント**：ワークスペースの Markdown ドキュメントを開きます。ドキュメントは中央に表示されるので、見ながら Agent に編集させられます。
- 他のページからもここにタスクが渡されます：人物ページの「Agent に把握させる」「Agent が返信を下書き」、リストの「一括準備」、今日の「同期して要約」。

## コンテキスト

- 今見ている連絡先とドキュメントは Agent に伝えられます。新しい質問で「この人」と言うと、Agent は現在選択中の人を読み取ります。
- 進行中のタスクは開始時の対象を保ちます。連絡先を切り替えても変わりません。

## 記録と権限

- ターミナルの出力はこのコンピュータに保存されます。終了または中断したセッションは「読み取り専用の記録」として表示され、検索やコピーができ、「入力可能な新しいセッション」で続けられます。
- 初回の信頼確認、サインイン、ツールの権限は、すべてターミナルであなたが確認します。
- Agent はレビュー待ちの下書きを保存できるだけで、送信ツールはありません。
- Agent が行った変更は、その人の「Agent メモリ」に自動で記録されます。

## 進捗と結果

- ターミナル上部の「Agent の進捗」に、Agent 自身が報告した状態（進行中〈一括処理は 3/12 のように表示〉、完了、返信待ち、進行不可）と最新のステップが表示されます。開くと「やり取りを読む · Maya Chen」「下書きを保存 · Maya Chen」のように各ステップが読める形で並び、クリックすると関係する人物・下書き・文書を開けます。
- 下書きの保存やレポート作成のあと、Agent はそれを中央に開いて見せることができます。キーボードはターミナルに残るので、そのまま入力を続けられます。何かを編集中のときは割り込まず、上部に「Agent が表示を提案しています：…」と表示されます。
- ダイアログは右側の Agent を覆わないため、下書きを確認しながら Agent と会話できます。
- Agent がある人物を処理しているあいだ、その人物のページに「Agent が作業中」と表示され、クリックすると該当セッションに移動します。
- パネルを閉じているときに Agent が完了したり返信を求めたりすると、上部に一行で結果が表示され、今日ページの「Agent の最近の結果」にも並びます。
- 同時に実行できるセッションは 6 つまでです。上限のときに新しいタスクを始めると、最も古い完了済み・返信待ちのセッションを終了するよう提案されます（記録は残ります）。
- 「人物」ページで連絡先を選択してから「この人たちに…」と頼むと、Agent は選択内容を読み取れます。セッション一覧にも各セッションの最新状態が表示されます。

## Agent が使えるツール（MCP）

| 用途 | ツール |
|---|---|
| ワークスペースを理解 | `workspace.guide`（プレイブック、ステージ、フィールド、書き方の好み）、`context.get` |
| 人物を理解 | `memory.read`、`contact.get`、`timeline.get`、`source.facts`、`contact.search` |
| ソースユーザーの把握 | `source.people`（未関連付けを含むすべてのソースユーザーを検索）、`source.person`（事実・変化・イベント） |
| 記録する | `memory.append`、`dossier.write_section`、`contact.update`、`contact.follow_up`、`channel.add`、`preferences.add` |
| 下書き | `draft.save`（保存のみ。承認や送信はできません） |
| あなたとの連絡 | `task.report`（進捗 / 完了 / 返信待ち / 進行不可）、`ui.open`（人物・下書き・文書・リストを中央に表示） |
| リスト | `list.all`、`list.get`、`list.draft_save`、`list.decline` |
| 同期 | `mail.accounts`、`mail.sync`、`source.list`、`source.sync` |
| ドキュメント | `document.list`、`document.read`、`document.create`、`document.replace` |
