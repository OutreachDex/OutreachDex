# 連絡先のインポート

## CSV / TSV からインポート

1. 「人物」ページで「インポート」をクリックし、ファイルを選びます。Excel の場合は先に「CSV UTF-8 で保存」してください。
2. アプリが最初の数行をプレビューし、列名からフィールドを自動で対応付けます。中国語と英語の列名を認識します。例：姓名 / Name、邮箱 / Email、公司 / Affiliation、备注 / Notes。
3. 各列の上で対応するフィールドを調整するか、「インポートしない」を選びます。1 つの列を「Name」に対応させる必要があります。
4. 「インポート」をクリックします。

インポートのルール：

- 既存の連絡先とはまず**メール**、次に**名前**で照合し、一致すれば空でないフィールドを更新し、なければ新規作成します。
- メール、ホームページ、X、Instagram は連絡チャネルにも追加されます。
- 「ステージ」列の値はワークスペースの設定にあるステージ名である必要があり、それ以外は無視され、警告が表示されます。

## コマンドラインでインポート

```sh
globalcontact import contacts.csv --workspace /path/to/workspace
```

対象のワークスペースはデスクトップアプリで使用中であってはいけません。新しいワークスペースを作成するときは、`--template user-relationships` などでテンプレートを指定できます。

## 表でまとめて整理

「人物」ページの「表の編集」で連絡先の表が開き、行の追加やフィールドの変更を直接行えます。まとめて整理するのに便利です。
