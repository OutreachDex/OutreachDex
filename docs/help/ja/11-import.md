# 連絡先のインポート

## CSV / TSV からインポート

1. 「人物」ページで「インポート」をクリックし、「連絡先（CSV / TSV）」を選んでからファイルを選びます。Excel の場合は先に「CSV UTF-8 で保存」してください。
2. アプリが最初の数行をプレビューし、列名からフィールドを自動で対応付けます。中国語と英語の列名を認識します。例：姓名 / Name、邮箱 / Email、公司 / Affiliation、备注 / Notes。
3. 各列の上で対応するフィールドを調整するか、「インポートしない」を選びます。1 つの列を「Name」に対応させる必要があります。
4. 「インポート」をクリックします。

インポートのルール：

- 既存の連絡先とはまず**メール**、次に**名前**で照合し、一致すれば空でないフィールドを更新し、なければ新規作成します。
- メール、ホームページ、X、Instagram は連絡チャネルにも追加されます。
- 「ステージ」列の値はワークスペースの設定にあるステージ名である必要があり、それ以外は無視され、警告が表示されます。

## WhatsApp と LinkedIn の会話をインポート

会話の履歴は、ご自身で書き出したファイルから読み込みます。OutreachDex が WhatsApp や LinkedIn にログインすることはないので、アカウントへのリスクも、レート制限にかかることもありません。

「人物」ページで「インポート」をクリックし、次のどちらかを選びます。

- **WhatsApp のチャット**：WhatsApp で 1 対 1 のチャットを開き、相手の名前 →「チャットをエクスポート」→「メディアなし」を選び、できた `.zip`（iPhone）または `.txt`（Android）を選択します。グループチャットは読み込めないので、相手ごとのチャットを書き出してください。
- **LinkedIn のメッセージ**：LinkedIn の 設定 → データプライバシー →「データのコピーを取得」で「メッセージ」と「つながり」を選び、メールで届く `.zip` を選択します（最大 1 日ほどかかります）。

プレビューには 1 対 1 の会話ごとに、登録先の連絡先が表示されます。

- 連絡先のチャネルにある WhatsApp の番号や LinkedIn のプロフィール、次に LinkedIn のつながりのメールアドレス、最後に完全に同じ名前の順で照合します。別の連絡先に変更する、新しく作る、「インポートしない」を選ぶこともできます。
- どの参加者があなたかを判断できないときは選択を求めます。WhatsApp の書き出しで日付がどちらにも読める（01/02）場合は、日と月のどちらが先かを選んでください。

インポートで書き込まれるもの：

- メッセージはワークスペースの `chats/whatsapp/…` または `chats/linkedin/…` に、会話ごと・日ごとの Markdown ファイルとして保存されます。
- 連絡先のタイムラインには、日ごと・方向ごとに 1 件ずつ記録されます（「WhatsApp: 最後のメッセージ (+3 more)」）。開くとその日のメッセージをすべて読めます。
- 「最終連絡日」と「最終返信日」は先に進むだけで、ステージは最後に書いた側に合わせて変わります。終了済みや連絡しないステージの人はステージが変わりません。
- WhatsApp の番号や LinkedIn のプロフィールが連絡先のチャネルに追加され、次回のインポートでは自動で照合されます。

同じチャットやアーカイブの新しい書き出しは、いつでも読み込めます。読み込み済みのメッセージは認識され、新しいものだけが追加されます。

## コマンドラインでインポート

```sh
globalcontact import contacts.csv --workspace /path/to/workspace
```

対象のワークスペースはデスクトップアプリで使用中であってはいけません。新しいワークスペースを作成するときは、`--template user-relationships` などでテンプレートを指定できます。

## 表でまとめて整理

「人物」ページの「表の編集」で連絡先の表が開き、行の追加やフィールドの変更を直接行えます。まとめて整理するのに便利です。
