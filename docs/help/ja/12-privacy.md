# プライバシーとセキュリティ

- **データはあなたの手元に**：連絡先、人物メモ、下書き、メール、ソースのイベントは、あなたが選んだワークスペースフォルダに保存されます。OutreachDex にはクラウドサービスがなく、利用データも収集しません。
- **パスワードとトークン**：メールのパスワードとデータソースのトークンは、このコンピュータの鍵で暗号化してアプリデータフォルダに保存され、ワークスペースのファイルには書き込まれません。
- **AI アシスタント**：分析には、このコンピュータでサインインしている Claude Code / Codex を使います。分析中、アシスタントはワークスペースのデータを読むことができ、関連する内容はそのサービスの規約に従って各モデル提供元に送信されます。
- **自動送信はしない**：アシスタントが保存できるのはレビュー待ちの下書きだけです。どの送信にもあなたの承認と、確認ダイアログでのもう一度の確定が必要です。
- **迷惑をかけない**：「連絡しない」のアドレスと連絡先は、どのリストにも選ばれず、送信もできません。リストのメッセージには 1 日の上限があります。
- **データソースは読み取り専用**：バックエンドの読み取り専用エンドポイントだけを呼び出し、manifest で宣言された属性だけを保存します。https が必須です。
- **信頼できない内容**：メール、Web ページ、ソースのイベントの本文は、アシスタントにとって証拠にすぎず、指示として実行されることはありません。
