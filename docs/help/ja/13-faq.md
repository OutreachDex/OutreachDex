# よくある質問

**右側の Agent で新しいセッションを開けない、またはコマンドラインが見つからないと表示される**
このコンピュータに Claude Code または Codex がインストールされサインイン済みであること（ターミナルで正常に動くこと）、そして「設定 → AI アシスタント」に「検出済み」と表示されていることを確認してください。特別な場所にインストールしている場合は「詳細」でパスを指定できます。Agent の「セッション一覧」で別のアシスタントに切り替えることもできます。

**メールボックスに接続できない**
ほとんどのメールボックスでは「アプリ用パスワード」が必要で、メールボックスの設定で IMAP / SMTP を有効にする必要があります。「設定 → メールアカウント」で「テスト」をクリックすると具体的な理由がわかります。プロキシが必要な場合はプロキシ URL を入力してください。

**ソースのチェックに失敗する**
チェック結果に従って、バックエンドのエンドポイントを項目ごとに修正してください。例：ページングが進まない、フィールドの形式が正しくない、manifest がない。開発者は `globalcontact source check` でコマンドラインから繰り返しテストできます。

**同期後、「確認待ち」の人がいる**
これらの人のメールはあなたの連絡先と一致していますが、バックエンドではそのメールが確認されていません。同一人物か確認してください。「別人」を選ぶと、以後は表示されません。

**下書きに「送信結果を確認してください」と表示される**
送信中に接続が切れたため、メールが送られたか確認できません。メールボックスの送信済みフォルダで確認してください。二重送信を防ぐため、この下書きはロックされています。

**送信が拒否された：「連絡しない」リストにある / 1 日の上限に達した**
迷惑を防ぐための保護です。どうしても連絡が必要な場合は、ワークスペースの `suppression.txt` からアドレスを削除するか、`globalcontact.toml` の `[outreach] daily_limit` を調整してください。

**ワークスペースを開くと、別のプロセスで開かれていると表示される**
1 つのワークスペースは同時に 1 つのウィンドウまたはコマンドラインのインポートでしか使えません。先に他のウィンドウを閉じてください。

**globalcontact.toml の変更が反映されない**
ワークスペースを開き直してください。形式に誤りがある場合は、エラーの具体的な場所が表示されます。
