# キーボードショートカット

| ショートカット | 操作 |
|---|---|
| ⌘ / Ctrl + K | 全体検索：人物、リスト、下書き、ページ、よく使う操作（ターミナル内では横取りしません） |
| ⌘ / Ctrl + J | Agent の表示 / 非表示（ターミナル内でも使えます） |
| ⌘ / Ctrl + S | 現在のドキュメントまたは下書きを保存 |
| ⌘ / Ctrl + F | Agent のターミナルで記録を検索 |
| ↑ ↓ / J K | 「人物」リストで移動。Enter で開く |
| J / K | 人物ページで次 / 前の人へ |
| Esc | ダイアログを閉じる。人物ページからリストに戻る |
| ← → / Home / End | 人物ページのセクションタブを切り替え |
| Tab / Shift + Tab | ダイアログ内でフォーカスを移動（ダイアログの外には出ません） |
