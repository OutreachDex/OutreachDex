# 빠른 시작

OutreachDex는 중요한 한 사람 한 사람과 일대일 관계를 쌓도록 돕습니다. 상대를 이해하고, 상대에 맞춘 메시지를 준비하고, 직접 검토한 뒤 보내며, 꾸준히 후속 연락을 이어갑니다. 모든 데이터는 직접 고른 **워크스페이스 폴더**에 저장됩니다.

## 처음 사용할 때

1. **워크스페이스 만들기**: 왼쪽 위 워크스페이스 이름 → 새 워크스페이스…를 클릭하고, 템플릿을 고른 뒤 빈 폴더를 선택합니다.
   - **빈 템플릿**: 범용 단계. 모든 일대일 연락에 적합합니다.
   - **전문가 연락**: 학자나 업계 전문가를 조사하고, 처음 연락하고, 후속 연락합니다.
   - **제품 사용자 관계**: 제품 사용자의 목표와 피드백을 이해하고 문제 처리를 후속 관리합니다.
2. **연락처 추가**: 「사람」 페이지에서 「새 연락처」를 클릭하거나, 「가져오기」로 CSV / 표에서 명단을 가져옵니다([연락처 가져오기](11-import.md) 참고).
3. **메일 연결**(선택): 「설정 → 메일 계정」에서 받는 메일(IMAP)과 보내는 메일(SMTP) 계정을 추가합니다. 받은 메일은 해당 연락처로 자동 분류됩니다.
4. **Agent 준비**(선택): 분석과 초안 작성에는 이 컴퓨터에서 로그인한 Claude Code 또는 Codex를 사용합니다. 처음 사용하기 전에 터미널에서 로그인하세요. OutreachDex에는 둘 다 포함되어 있지 않습니다. 설치되어 있지 않으면 Agent 패널과 '설정 → 도우미'에 설치 명령이 표시됩니다.

## 평소 사용법

- 「**오늘**」을 엽니다: 답장을 기다리는 사람, 검토 대기 중인 초안, 후속 연락이 필요한 사람을 확인합니다.
- **⌘ / Ctrl + K**로 사람, 리스트, 초안을 검색하고 Enter로 바로 엽니다.
- 사람을 엽니다: 인물 페이지에서 프로필, 활동 기록, 소스 사실을 봅니다. 「Agent에게 파악 요청」을 클릭하면 오른쪽 Agent가 상황을 정리하고, 「Agent 답장 초안」은 검토용 답장을 준비합니다.
- 초안을 수정하고 **승인**한 뒤, 보내는 계정을 골라 **발송을 확인**합니다. OutreachDex는 절대 자동으로 보내지 않습니다.

## 화면 구성

| 영역 | 역할 |
|---|---|
| 왼쪽 내비게이션 | 오늘, 사람, 리스트, 메일, 소스, 설정 |
| 가운데 | 현재 페이지: 리스트, 인물 페이지, 문서 |
| 오른쪽 Agent | 오른쪽에 고정된 명령줄 어시스턴트. ⌘ / Ctrl+J로 표시 / 숨기기, 왼쪽 가장자리를 드래그해 너비 조정 |

「설정 → 외관」에서 라이트 / 다크 / 시스템 설정 따르기, 그리고 편안함 / 촘촘함 두 가지 정보 밀도를 바꿀 수 있습니다.

인터페이스 언어는 「설정 → 외관 → 인터페이스 언어」에서 바꿀 수 있습니다: 中文 / English / 日本語 / 한국어.
