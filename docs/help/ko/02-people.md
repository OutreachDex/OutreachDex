# 사람과 인물 페이지

## 「사람」 페이지

모든 연락처가 표로 표시됩니다.

- **보기**: 전체, 답장 대기(내가 마지막으로 보낸 뒤 상대가 답장), 후속 연락(보낸 뒤 설정한 일수가 지나도 답장 없음).
- **검색과 필터**: 이름, 소속, 이메일로 검색하고 단계로 필터링합니다.
- **키보드**: ↑ ↓ 또는 J / K로 이동, Enter로 열기.
- **일괄 작업**: 여러 명을 체크하면(머리글의 체크박스로 현재 목록 전체 선택) 단계 일괄 변경, 후속 연락 예약(내일 / 3일 후 / 1주 후 / 1개월 후 / 지우기), CSV 내보내기를 할 수 있습니다.
- **내보내기**: 「내보내기」는 현재 목록의 모든 필드를 CSV로 내보냅니다(BOM 포함이라 Excel에서도 글자가 깨지지 않습니다).
- **표 편집**: 표 편집기에서 연락처, 채널, 소스 ID, 활동 데이터를 직접 한꺼번에 정리합니다.

## 인물 페이지

왼쪽은 내용, 오른쪽은 속성과 연락 채널입니다.

| 섹션 | 내용 |
|---|---|
| 개요 | 다음 단계, 소스 사실, 연락 계기, AI 배경 요약, Agent 메모리, 유의 사항, 처리 대기 초안, 최근 활동 |
| 초안 | 이 사람의 모든 초안. 채널별로 필터링 |
| 활동 기록 | 이메일, 기록한 자료와 피드백, 소스 이벤트 |
| 인물 노트 | 이 사람의 Markdown 인물 노트. 바로 편집할 수 있습니다 |

- **사실과 추론을 구분**: 「자료」「소스」 태그는 기록된 사실이고, 「AI 추론」 태그는 어시스턴트의 판단입니다. 사용하기 전에 확인하세요.
- **연락처 전환**: 상단 바의 ↑ ↓ 또는 키보드 K / J로 이전 / 다음 사람으로 이동하고, Esc로 목록에 돌아갑니다.
- **단계**: 오른쪽 속성에서 변경합니다. 메시지를 보내면 자동으로 「보냄」 계열 단계로, 답장을 받으면 「답장함」 계열 단계로 바뀝니다. 단계 이름은 워크스페이스 설정에서 바꿀 수 있습니다([워크스페이스와 설정](10-workspace.md) 참고).

## 프로필: 사용자 정의 필드

인물 페이지 오른쪽 열의 「프로필」에는 이 사람의 모든 필드가 나열됩니다. 클릭해서 수정하며, **입력란을 벗어나면 자동으로 저장됩니다**.

- **필드 추가**: 전화, 직책, 생일, 태그, 관계 등 「필드 추가」로 직접 추가할 수 있습니다.
  - 유형: 텍스트, 긴 텍스트, 숫자, 날짜, 링크, 예 / 아니요, 단일 선택, 다중 선택(태그).
  - 새 필드는 모든 연락처에 추가되며 워크스페이스의 연락처 표에 저장됩니다.
- **옵션**: 단일 선택 필드에서는 「＋ 새 옵션…」으로 옵션을 추가합니다. 다중 선택 필드는 쉼표로 구분해 바로 입력하면 새 태그가 자동으로 옵션에 추가됩니다.
- **앱이 관리하는 필드**: 마지막 연락 / 답장 시간, AI 요약, ID는 앱이 관리하므로 여기서 편집하지 않습니다.
- **변경 이력**: 오른쪽 열 아래의 「변경 이력」에서 각 필드가 언제 무엇에서 무엇으로 바뀌었는지 볼 수 있습니다.

## 중복 연락처 합치기

한 사람에게 레코드가 두 개 있으면, 남길 레코드의 인물 페이지에서 「합치기…」를 클릭하고 다른 레코드를 선택합니다.

- 합치기 전에 옮겨질 내용이 표시됩니다: 채널, 활동 기록, 소스 ID, 초안, 기록한 자료, 채워질 빈 필드.
- 합칠 때:
  - 채널의 중복을 제거합니다;
  - 빈 필드는 다른 레코드의 값으로 채우고, 기존 값은 그대로 둡니다;
  - 마지막 연락 / 답장 시간은 더 최근 값을 사용합니다;
  - 합쳐지는 쪽의 인물 노트 본문은 끝에 덧붙입니다.
- 합쳐진 레코드는 삭제되며 되돌릴 수 없습니다(필요하면 git이나 백업으로 워크스페이스를 복원하세요). 승인된 초안은 합친 뒤 다시 승인해야 합니다.

## 자료와 피드백 기록

인물 페이지에서 「자료 / 피드백 기록」을 클릭하면 웹 발췌, SNS 게시물, 사용자 피드백 원문, 인터뷰 결과 등을 붙여넣고 출처를 남길 수 있습니다. 「저장하고 Agent에게 분석 요청」을 선택하면 오른쪽 Agent가 이 기록을 바탕으로 다음 단계를 분석합니다.

링크만 저장하면 웹 페이지 내용을 자동으로 가져오지 않습니다. 원문을 붙여넣어 주세요.
