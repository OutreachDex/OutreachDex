# 오늘

「오늘」은 처리해야 할 일을 우선순위 순으로 한 화면에 모아 보여 줍니다.

| 그룹 | 의미 |
|---|---|
| 내 답장 대기 | 상대가 최근 답장했고 아직 응답하지 않음 |
| 검토 대기 초안 | 어시스턴트나 내가 작성해 승인 또는 발송을 기다리는 초안 |
| 기한이 된 후속 연락 | 예약한 후속 연락일이 되었거나, 보낸 뒤 설정한 일수가 지나도 답장이 없음(일수는 「설정 → AI 어시스턴트 → 후속 연락 알림」에서 변경) |
| 판단 필요 | 데이터 소스에서 확인을 기다리는 ID 매칭, 동기화에 실패한 소스 |

어느 행이든 클릭하면 해당 사람, 섹션, 초안이 바로 열립니다. 통계 아래의 「동기화 후 요약」은 오른쪽 Agent가 연결된 메일함과 데이터 소스를 동기화하고, 새 소식이 있는 사람을 긴급도 순으로 정리하게 합니다(정리만 하고 초안 작성이나 발송은 하지 않습니다). 보류 또는 「연락 안 함」 단계의 사람은 답장 대기와 후속 연락에 표시되지 않습니다.

## 시작 체크리스트

새 워크스페이스의 「오늘」 상단에는 체크리스트가 표시됩니다: 연락처 추가, 메일 연결, 데이터 소스 연결, AI 어시스턴트 준비. 완료한 항목은 자동으로 체크되며, 모두 완료하거나 「다시 보지 않기」를 클릭하면 숨겨집니다.

## 후속 연락 알림

각 사람에게 「다음 후속 연락」 날짜를 지정할 수 있으며, 인물 페이지의 「다음 단계」 아래에서 설정합니다:

- 「내일」「3일 후」「1주 후」를 한 번에 고르거나 날짜를 선택합니다. 「지우기」로 알림을 취소합니다.
- **메시지를 보내면**(메일 발송 또는 발송됨으로 표시) 「후속 연락 알림」 일수 뒤로 자동 예약됩니다.
- **상대가 답장하면** 알림이 자동으로 지워지고, 그 사람은 「내 답장 대기」에 표시됩니다.
- **부재중 자동 답장을 받으면** 메일에 적힌 복귀 날짜(예: 「11月10日」「November 10」) 다음 날로 예약됩니다. 날짜를 인식하지 못하면 1주 뒤로 예약됩니다.
- **꾸준히 연락**: 후속 연락 표시줄 오른쪽에서 빈도(매주, 2주마다, 매월, 분기마다, 반년마다)를 고릅니다. 설정하면 메시지를 보낼 때 이 빈도로 다음 후속 연락이 예약되고, 후속 연락이 예약되지 않은 채 마지막 활동이 이 빈도를 넘기면 알려 줍니다.
- 후속 연락일이 된 사람은 「기한이 된 후속 연락」과 「사람 → 후속 연락」에 표시됩니다.
