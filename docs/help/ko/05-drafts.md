# 초안, 검토, 발송

발송은 항상 직접 합니다: **수정 → 승인 → 계정을 골라 발송 확인**.

## 수정과 승인

- 인물 페이지에서 「초안 쓰기」를 클릭하거나, 어시스턴트가 만든 초안을 엽니다.
- **참고 초안**을 골라 나란히 비교할 수 있습니다. 예를 들어 두 어시스턴트가 각각 쓴 경우입니다.
- 대화상자를 닫거나 페이지를 바꾸면 저장하지 않은 수정은 이번 세션 동안 임시 보관되고, 초안에 「임시 보관된 수정 있음」이 표시됩니다. 임시 보관은 저장이 아니며, 앱을 종료하기 전에 알려 줍니다.
- 「저장하고 승인」을 클릭하면 초안이 승인 상태가 됩니다. **승인 후 내용을 조금이라도 바꾸면 다시 승인해야 합니다.**

## 검토할 때의 안내

- **AI 원고**: 어시스턴트가 쓴 초안은 원문을 보관합니다. 수정한 뒤 「참고 초안」에서 「AI 원고(수정 전)」를 고르면 나란히 비교할 수 있습니다.
- **오래되었을 수 있음**: 초안을 만든 뒤 상대가 다시 메일을 보냈다면 초안에 「오래되었을 수 있음」이 표시됩니다. 발송하거나 발송됨으로 표시하기 전에 「최신 메일을 확인했습니다」에 체크해야 하며, 백엔드에서도 다시 확인합니다.
- **문구 점검**: 본문 아래에 상투적인 첫머리, AI 같은 어휘, 지나친 길이, 너무 많은 질문이나 링크, 과도한 느낌표나 대시를 알려 줍니다. 안내일 뿐 자동으로 고치지 않습니다.
- **바꾸지 않은 자리표시자**: `{{name}}`, `[姓名]` 등은 차단되어 보낼 수 없습니다.

## 어시스턴트가 나처럼 쓰도록

초안을 검토할 때 본문 아래의 「**글쓰기 선호 기억하기**」를 클릭합니다. 예: 「첫머리에 인사말 없이 바로 용건을 밝힌다」「중국어는 150자 이내」.

- 선호는 워크스페이스의 `preferences.md`에 저장됩니다;
- 이후의 분석, 초안 작성, 리스트 일괄 준비는 모두 Agent 터미널에서 이루어지며 모두 이 선호를 따릅니다;
- 「설정 → 글쓰기 선호」에서 보고, 수정하고, 삭제할 수 있습니다.

## 받는 사람 확인

메일 초안의 받는 사람은 그 사람의 알려진 주소(프로필 메일, 연락 채널의 메일, 연결된 소스의 메일)여야 합니다. 주소를 잘못 적었거나 Agent가 맞지 않는 주소를 쓰면 받는 사람 아래에 노란 안내와 알려진 주소가 표시되고, 클릭해 바로 고칠 수 있습니다. 새 주소로 보내려면 보내기 전에 한 번 더 확인합니다.

## 발송

- **이메일**: 승인된 이메일 초안에서 보내는 계정(SMTP)을 고르고 「이메일 보내기」를 클릭한 뒤, 확인 대화상자에서 한 번 더 확인합니다.
- **기타 채널**(X, WeChat, Instagram 등): 「본문 복사」를 클릭해 해당 플랫폼에서 직접 보낸 뒤, 돌아와서 「발송됨으로 표시」를 클릭합니다.

발송 전에 앱은 다음 세 가지를 반드시 확인하며, 하나라도 통과하지 못하면 보내지 않습니다:

1. 받는 주소가 「연락 안 함」 명단(워크스페이스의 `suppression.txt`)에 없음;
2. 연락처의 단계가 「연락 안 함」이 아님;
3. 리스트에서 보내는 메시지가 하루 한도를 넘지 않음.

잠시 모두 멈춰야 할 때(반송이 늘었거나 발송 설정을 점검하려는 경우 등)는 「설정 → AI 어시스턴트」에서 「**모든 발송 일시 중지**」에 체크합니다. 이메일 발송과 「발송됨으로 표시」가 모두 거부되며, 초안은 계속 수정하고 승인할 수 있고, 상단 바에는 「발송 일시 중지됨」이 계속 표시됩니다.

발송 중 네트워크가 끊기면 중복 발송을 막기 위해 초안이 「발송 결과를 확인하세요」로 표시되고 잠깁니다. 메일함의 보낸 편지함에서 확인하세요.
