# 데이터 소스 연결

데이터 소스를 연결하면 업무 백엔드(예: 제품의 사용자 관리 화면, 티켓 시스템)가 「사람」과 「이벤트」를 OutreachDex에 넘겨줍니다. 그러면 각 사람의 요금제, 사용 현황, 피드백을 보고 이를 바탕으로 분석하고 연락할 수 있습니다.

## 백엔드에서 할 일

백엔드는 **GCSP/1** 규격에 따라 읽기 전용 엔드포인트 3개 `/manifest`, `/people`, `/events`를 구현하고 읽기 전용 토큰을 발급합니다. 전체 규격은 프로젝트의 `docs/gcsp.md`에 있으며 Go와 Node 참고 구현도 있습니다. 개발자는 먼저 명령줄에서 테스트할 수 있습니다:

```sh
globalcontact source check https://你的后台/gcsp --token <token>
```

## 연결

1. 「소스」 페이지 → 소스 연결을 엽니다.
2. 소스 주소와 토큰을 입력합니다. 헤더 기본값은 `Authorization`이며, 백엔드가 다른 헤더를 쓸 때만 바꿉니다.
3. 「검사」를 클릭합니다: 앱이 각 엔드포인트가 규격에 맞는지 항목별로 확인하고 처음 몇 명을 미리 보여 줍니다.
   - **실패** 항목은 반드시 백엔드에서 고쳐야 합니다;
   - **경고** 항목은 일단 연결할 수 있지만, 나중에 백엔드에서 고치는 것이 좋습니다.
4. 「연결하고 동기화」를 클릭합니다. 이후 설정한 간격(기본 60분)마다 자동으로 증분 동기화되며, 언제든 「지금 동기화」할 수 있습니다.

주소는 `https://`여야 합니다(로컬 테스트에는 `http://127.0.0.1`을 쓸 수 있습니다). 토큰은 이 컴퓨터에 암호화되어 저장됩니다. OutreachDex는 읽기 전용 엔드포인트만 호출하며 백엔드에 아무것도 쓰지 않습니다.

## ID 매칭

동기화된 각 사람은 다음 규칙으로 연락처와 연결됩니다:

| 상황 | 결과 |
|---|---|
| 백엔드에서 인증된 이메일이 어떤 연락처와 같음 | **자동 연결** |
| 이메일은 같지만 백엔드에서 인증되지 않음 | 「**확인 대기**」로 들어가 같은 사람인지 직접 판단 |
| 일치 없음 | 「**미연결**」로 남음. 「연락처로 만들기」 또는 기존 연락처에 「연결…」할 수 있음 |

- 이름이 같다고 자동으로 합치지 않습니다.
- 「아님」을 고르면 다시 동기화해도 다시 제안하지 않습니다.
- 연결하면 이 사람의 소스 이벤트가 활동 기록에 추가되고, 소스 이메일이 연락 채널에 추가됩니다.

## 아직 연락처가 아닌 사용자 파악하기

"소스" 페이지에서 아무 사람(연결되지 않은 사람 포함)이나 클릭하면 소스에 있는 사실, 속성 변화, 이벤트를 볼 수 있고, 이벤트를 클릭하면 원문을 엽니다. "Agent에게 파악 요청"을 누르면 오른쪽 Agent가 이 자료를 읽고 사용 단계, 결제, 겪는 문제, 활동을 요약해 지금 연락할 가치가 있는지 판단합니다. 먼저 연락처로 만들 필요가 없습니다. 가치가 있으면 "연락처로 만들기" 후 초안을 씁니다.

Agent는 모든 소스 사용자를 검색할 수도 있습니다. 예: "크레딧을 다 썼는데 최근에도 쓰고 있는 무료 사용자는 누구?"

## 소스 사실

연결된 사람은 인물 페이지의 「소스 사실」 카드에 백엔드가 제공한 속성(요금제, 크레딧, 가입일 등)이 소스와 동기화 시각과 함께 표시됩니다. 백엔드가 개인정보로 표시한 속성은 따로 표시됩니다. 백엔드가 manifest에 선언한 속성만 저장됩니다.

## 변경 기록

동기화할 때마다 OutreachDex는 이 사람의 속성을 비교해 변화를 기록합니다. 예: 「요금제: free → pro」「남은 크레딧: 20 → 0」.

- 인물 페이지 「소스 사실」 카드에서 「변경 기록」을 클릭하면 최근 변화를 볼 수 있습니다.
- 전체 기록은 워크스페이스의 `sources/<소스>/people/<ID>.md`에 저장됩니다. 위쪽은 현재 속성, 아래쪽은 시각이 붙은 변경 로그이며, 바로 열어 읽거나 Agent에게 분석을 맡길 수 있습니다.
- 백엔드가 manifest에 선언한 속성만 기록합니다.

## 새 연락처의 언어

소스에서 만든 연락처에는 언어가 정해지고 Agent는 그 언어로 초안을 씁니다. 순서는 소스가 알려 준 그 사람의 언어 → 소스 "…" 메뉴의 "새 연락처 언어" → 소스가 선언한 기본 언어 → 워크스페이스 기본값입니다. ThumbnailSnap 같은 영어 사이트라면 "새 연락처 언어"를 English로 설정하세요. 초안 언어가 연락처 언어와 맞지 않으면 검토 화면에 안내가 표시됩니다.
