# 리스트와 콜드 아웃리치

리스트는 연락처와 데이터 소스에서 **지금 연락할 가치가 있는 사람**을 찾아 줍니다. 어시스턴트가 한 명씩 조사하고 초안을 쓰면, 직접 한 명씩 검토합니다. 발송은 항상 직접 결정하며, **일괄 발송도 자동 발송도 하지 않습니다**.

## 리스트 만들기

「리스트」 페이지에서 ＋를 클릭하고 다음을 입력합니다:

- **이름과 목적**: 목적은 왜 이 사람들에게 연락하는지 어시스턴트에게 알려 줍니다. 예: 「어디서 막혔는지, 도움이 필요한지 알아보기」.
- **후보 출처**: 기존 연락처, 또는 어떤 데이터 소스의 사람(아직 연결되지 않은 사람 포함).
- **채널, 분석 목적, 비즈니스 배경**.
- **필터 조건**(모두 충족해야 함):
  - 소스 속성: 예) 요금제 = free, 남은 크레딧 ≤ 0;
  - 이벤트: 예) 30일 안에 「크레딧 소진」이 있고 「크레딧 구매」가 없음;
  - 이벤트 횟수: 예) 14일 안에 「작업 실패」 2회 이상, 「크레딧 구매」 정확히 0회(일수를 비우면 전체 기간);
  - 연락 상태: 단계, 연락한 적 없음, 마지막 연락 후 N일 초과;
  - 연락처 필드: 예) 프로젝트, 소속.

편집하는 동안 조건에 맞는 인원과 처음 몇 명이 실시간으로 표시됩니다. 「연락 안 함」인 사람은 자동으로 제외됩니다. 리스트는 워크스페이스의 `lists/` 폴더에 저장됩니다.

## 일괄 준비

일부를 체크하거나 바로 「일괄 준비」를 클릭하면, 그 사람들이 대기열에 들어가 오른쪽 Agent가 **한 명씩** 처리합니다(모든 단계가 터미널에 표시됩니다):

1. 소스에 있지만 아직 연결되지 않은 사람은 먼저 연락처로 만듭니다;
2. 선정 근거(소스 사실과 활동 기록)를 확인합니다;
3. 지금 연락하는 것이 정말 상대에게 도움이 된다면 검토 대기 메시지를 쓰고, 첫머리에 왜 지금 연락하는지 밝힙니다. 자료가 부족하면 초안을 쓰지 않고 멤버 표에 이유를 적습니다.

준비에는 이 컴퓨터에서 로그인한 Claude Code / Codex를 쓰며 모델 사용량이 소모됩니다. Agent가 중단되면 리스트 위의 「Agent에게 계속 요청」으로 이어서 처리합니다. 「대기열 취소」도 할 수 있습니다. 각 사람이 선정된 이유는 멤버 표에 표시됩니다.

## 한 명씩 검토

「한 명씩 검토」를 클릭합니다:

- 왼쪽에는 「왜 지금 연락하나」와 소스 사실, 오른쪽에는 초안이 있습니다.
- 작업: **저장**, **승인하고 다음**, **건너뛰기**, **연락 안 함**.
- 승인해도 발송되지 않습니다. 보내려면 초안에서 「발송하러 가기…」를 클릭하고 보내는 계정을 골라 확인합니다.

## 방해하지 않기

- **연락 안 함**: 주소가 워크스페이스의 `suppression.txt`에 기록되고, 연락처 단계가 「연락 안 함」으로 바뀌며, 이 초안은 폐기됩니다. 이후 모든 리스트에서 제외되고 발송도 거부됩니다.
- **하루 한도**: 하루에 보낼 수 있는 리스트 메시지의 최대 수(기본 20, 이메일과 수동 「발송됨으로 표시」 모두 포함). `globalcontact.toml`의 `[outreach] daily_limit`에서 바꿉니다. 리스트 페이지 오른쪽 위에 오늘 보낸 수가 표시됩니다.
