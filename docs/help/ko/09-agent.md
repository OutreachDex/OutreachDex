# Agent 작업 공간

오른쪽 Agent는 실제 명령줄 어시스턴트(이 컴퓨터의 Codex 또는 Claude Code)이며, OutreachDex 도구로 연락처와 문서를 읽고 씁니다.

## 기본 조작

- **표시 / 숨기기**: ⌘ / Ctrl+J, 또는 상단 바의 Agent를 클릭합니다. 숨겨도 세션은 계속 실행됩니다.
- **너비 조정**: 왼쪽 가장자리를 드래그하거나, 구분선에 포커스를 두고 방향키를 씁니다. 두 번 클릭하면 기본값으로 돌아갑니다.

패널은 위에서 아래로 세 부분뿐입니다:

1. **상단 바**: 초록 점은 세션이 실행 중이라는 뜻이고, 옆에 현재 세션 이름이 있습니다. 오른쪽에는 「세션 목록」「워크스페이스 문서」「새 세션」「숨기기」가 차례로 있습니다.
2. **빠른 작업**: 지금 보고 있는 사람을 보여 주고, 아래에 세 버튼이 있습니다——「이 사람 파악」「답장 초안」「동기화 후 요약」(연결된 메일함과 데이터 소스를 동기화하고 새 소식이 있는 사람을 정리). 버튼마다 새 세션을 엽니다.
3. **터미널**: Agent의 모든 단계가 여기에 표시되며, 바로 입력해 이어서 물을 수 있습니다. 「Enter ↵」는 Enter 키를 한 번 보냅니다.

- **세션 목록**: 이전 세션으로 전환하고, 현재 세션 이름을 바꾸고, 새 세션에 Codex와 Claude Code 중 무엇을 쓸지 고릅니다.
- **워크스페이스 문서**: 워크스페이스의 Markdown 문서를 엽니다. 문서는 가운데에 표시되므로 보면서 Agent에게 수정을 맡길 수 있습니다.
- 다른 페이지에서도 이곳으로 작업을 넘깁니다: 인물 페이지의 「Agent에게 파악 요청」「Agent 답장 초안」, 리스트의 「일괄 준비」, 오늘의 「동기화 후 요약」.

## 컨텍스트

- 지금 보고 있는 연락처와 문서가 Agent에게 전달됩니다. 새 질문에서 「이 사람」이라고 하면 Agent는 현재 선택된 사람을 읽습니다.
- 이미 진행 중인 작업은 시작할 때의 대상을 유지하며, 연락처를 바꿔도 달라지지 않습니다.

## 기록과 권한

- 터미널 출력은 이 컴퓨터에 저장됩니다. 끝났거나 중단된 세션은 「읽기 전용 기록」으로 표시되며, 검색하고 복사한 뒤 「입력 가능한 새 세션」으로 이어갈 수 있습니다.
- 처음의 신뢰 확인, 로그인, 도구 권한은 모두 터미널에서 직접 확인합니다.
- Agent는 검토 대기 초안만 저장할 수 있으며 발송 도구가 없습니다.
- Agent가 한 변경은 그 사람의 「Agent 메모리」에 자동으로 기록됩니다.

## 진행 상황과 결과

- 터미널 위의 "Agent 진행 상황" 줄에 Agent가 직접 보고한 상태(진행 중 — 일괄 작업은 3/12처럼 표시, 완료, 답장 대기, 막힘)와 최근 단계가 표시됩니다. 펼치면 "활동 기록 읽기 · Maya Chen", "초안 저장 · Maya Chen"처럼 각 단계를 읽기 쉽게 볼 수 있고, 클릭하면 관련 사람·초안·문서를 엽니다.
- 초안을 저장하거나 보고서를 쓴 뒤 Agent가 가운데 영역에 바로 열어 보여 줄 수 있습니다. 키보드는 터미널에 남아 있어 계속 입력할 수 있습니다. 다른 것을 편집 중이면 방해하지 않고 상단에 "Agent가 보여 드리려는 항목: …"을 표시합니다.
- 대화 상자는 오른쪽 Agent를 가리지 않으므로 초안을 검토하면서 Agent와 계속 대화할 수 있습니다.
- Agent가 어떤 사람을 처리하는 동안 그 사람의 페이지에 "Agent 작업 중"이 표시되고, 클릭하면 해당 세션으로 이동합니다.
- 패널이 닫혀 있을 때 Agent가 완료하거나 답장을 기다리면 상단에 한 줄로 결과를 알려 주며, 오늘 페이지의 "Agent 최근 결과"에도 표시됩니다.
- 세션은 동시에 최대 6개까지 실행됩니다. 가득 찬 상태에서 새 작업을 시작하면 가장 오래된 완료·답장 대기 세션을 종료하도록 제안합니다(기록은 유지됩니다).
- "사람" 페이지에서 연락처를 선택한 뒤 "이 사람들에게…"라고 말하면 Agent가 선택한 사람을 읽을 수 있습니다. 세션 목록에도 각 세션의 최신 상태가 표시됩니다.

## Agent가 쓸 수 있는 도구(MCP)

| 용도 | 도구 |
|---|---|
| 워크스페이스 파악 | `workspace.guide`(플레이북, 단계, 필드, 글쓰기 선호), `context.get` |
| 사람 파악 | `memory.read`, `contact.get`, `timeline.get`, `source.facts`, `contact.search` |
| 소스 사용자 파악 | `source.people`(연결되지 않은 사람 포함 전체 검색), `source.person`(사실·변화·이벤트) |
| 기록하기 | `memory.append`, `dossier.write_section`, `contact.update`, `contact.follow_up`, `channel.add`, `preferences.add` |
| 초안 | `draft.save`(저장만 가능, 승인이나 발송 불가) |
| 사용자와 소통 | `task.report`(진행 / 완료 / 답장 대기 / 막힘), `ui.open`(사람·초안·문서·리스트를 가운데에 표시) |
| 리스트 | `list.all`, `list.get`, `list.draft_save`, `list.decline` |
| 동기화 | `mail.accounts`, `mail.sync`, `source.list`, `source.sync` |
| 문서 | `document.list`, `document.read`, `document.create`, `document.replace` |
