# 연락처 가져오기

## CSV / TSV에서 가져오기

1. 「사람」 페이지에서 「가져오기」를 클릭하고 「연락처 (CSV / TSV)」를 선택한 뒤 파일을 고릅니다. Excel은 먼저 「CSV UTF-8로 저장」하세요.
2. 앱이 처음 몇 행을 미리 보여 주고, 열 이름에 따라 필드를 자동으로 대응시킵니다. 중국어와 영어 열 이름을 모두 인식합니다. 예: 姓名 / Name, 邮箱 / Email, 公司 / Affiliation, 备注 / Notes.
3. 각 열 위에서 대응할 필드를 조정하거나 「가져오지 않음」을 선택합니다. 한 열은 반드시 「Name」에 대응해야 합니다.
4. 「가져오기」를 클릭합니다.

가져오기 규칙:

- 기존 연락처와 먼저 **이메일**, 그다음 **이름**으로 매칭하며, 일치하면 비어 있지 않은 필드를 업데이트하고, 없으면 새로 만듭니다.
- 이메일, 홈페이지, X, Instagram은 연락 채널에도 추가됩니다.
- 「단계」 열의 값은 워크스페이스 설정의 단계 이름이어야 하며, 그렇지 않으면 무시되고 안내가 표시됩니다.

## WhatsApp 및 LinkedIn 대화 가져오기

대화 기록은 직접 내보낸 파일에서 가져옵니다. OutreachDex는 WhatsApp이나 LinkedIn에 로그인하지 않으므로 계정에 위험이 없고 요청 제한에 걸리지도 않습니다.

「사람」 페이지에서 「가져오기」를 누르고 다음 중 하나를 선택하세요.

- **WhatsApp 채팅**: WhatsApp에서 1:1 채팅을 열고 상대 이름 → "채팅 내보내기" → "미디어 제외"를 선택한 뒤, 만들어진 `.zip`(iPhone) 또는 `.txt`(Android)를 고르세요. 그룹 채팅은 가져올 수 없으니 사람별 채팅을 각각 내보내 주세요.
- **LinkedIn 메시지**: LinkedIn에서 설정 → 데이터 개인정보 → "데이터 사본 받기"로 가서 메시지와 1촌을 선택하고, 이메일로 받은 `.zip`을 고르세요(최대 하루 정도 걸릴 수 있습니다).

미리보기에는 1:1 대화마다 어느 연락처에 저장될지가 표시됩니다.

- 연락처 채널의 WhatsApp 번호나 LinkedIn 프로필, 그다음 LinkedIn 1촌의 이메일, 마지막으로 완전히 같은 이름 순으로 연결합니다. 다른 연락처로 바꾸거나, 새로 만들거나, "가져오지 않음"을 선택할 수 있습니다.
- 어느 참여자가 본인인지 알 수 없으면 선택하라고 묻습니다. WhatsApp 내보내기의 날짜가 두 가지로 읽힐 수 있으면(01/02) 일과 월 중 무엇이 먼저인지 고르세요.

가져오기로 기록되는 내용:

- 메시지는 워크스페이스의 `chats/whatsapp/…` 또는 `chats/linkedin/…` 아래에 대화별·날짜별 Markdown 파일로 저장됩니다.
- 연락처 타임라인에는 날짜와 방향마다 한 항목씩 기록됩니다("WhatsApp: 마지막 메시지 (+3 more)"). 열면 그날의 메시지를 모두 볼 수 있습니다.
- "마지막 연락"과 "마지막 답장"은 앞으로만 바뀌고, 단계는 마지막으로 메시지를 쓴 쪽을 따릅니다. 종료되었거나 연락하지 않는 단계의 사람은 단계가 그대로 유지됩니다.
- WhatsApp 번호나 LinkedIn 프로필이 연락처 채널에 추가되어 다음 가져오기에서 자동으로 연결됩니다.

같은 채팅이나 아카이브의 더 새로운 내보내기를 언제든지 가져올 수 있습니다. 이미 가져온 메시지는 인식되고 새 메시지만 추가됩니다.

## 명령줄로 가져오기

```sh
globalcontact import contacts.csv --workspace /path/to/workspace
```

대상 워크스페이스는 데스크톱 앱에서 사용 중이면 안 됩니다. 새 워크스페이스를 만들 때 `--template user-relationships` 등으로 템플릿을 지정할 수 있습니다.

## 표에서 한꺼번에 정리

「사람」 페이지의 「표 편집」은 연락처 표를 열며, 행을 추가하거나 필드를 바로 수정할 수 있어 한꺼번에 정리하기 좋습니다.
