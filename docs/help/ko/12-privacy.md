# 개인정보와 보안

- **데이터는 내 손에**: 연락처, 인물 노트, 초안, 메일, 소스 이벤트는 모두 직접 고른 워크스페이스 폴더에 저장됩니다. OutreachDex에는 클라우드 서비스가 없고 사용 데이터를 수집하지 않습니다.
- **비밀번호와 토큰**: 메일 비밀번호와 데이터 소스 토큰은 이 컴퓨터의 키로 암호화해 앱 데이터 폴더에 저장하며, 워크스페이스 파일에는 기록하지 않습니다.
- **AI 어시스턴트**: 분석에는 이 컴퓨터에서 로그인한 Claude Code / Codex를 씁니다. 분석하는 동안 어시스턴트는 워크스페이스 데이터를 읽을 수 있으며, 관련 내용은 해당 서비스 약관에 따라 해당 모델 제공업체로 전송됩니다.
- **자동 발송 없음**: 어시스턴트는 검토 대기 초안만 저장할 수 있습니다. 모든 발송에는 승인과 확인 대화상자에서의 한 번 더 확인이 필요합니다.
- **방해하지 않음**: 「연락 안 함」 주소와 연락처는 어떤 리스트에도 선택되지 않고 발송도 할 수 없습니다. 리스트 메시지에는 하루 한도가 있습니다.
- **데이터 소스는 읽기 전용**: 백엔드의 읽기 전용 엔드포인트만 호출하고, manifest에 선언된 속성만 저장합니다. https를 반드시 사용합니다.
- **신뢰할 수 없는 내용**: 메일, 웹 페이지, 소스 이벤트의 본문은 어시스턴트에게 증거일 뿐이며 지시로 실행되지 않습니다.
