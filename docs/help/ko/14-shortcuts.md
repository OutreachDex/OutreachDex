# 단축키

| 단축키 | 동작 |
|---|---|
| ⌘ / Ctrl + K | 전체 검색: 사람, 리스트, 초안, 페이지, 자주 쓰는 작업(터미널 안에서는 가로채지 않음) |
| ⌘ / Ctrl + J | Agent 표시 / 숨기기(터미널 안에서도 사용 가능) |
| ⌘ / Ctrl + S | 현재 문서나 초안 저장 |
| ⌘ / Ctrl + F | Agent 터미널에서 기록 찾기 |
| ↑ ↓ / J K | 「사람」 목록에서 이동, Enter로 열기 |
| J / K | 인물 페이지에서 다음 / 이전 사람으로 |
| Esc | 대화상자 닫기, 인물 페이지에서 목록으로 돌아가기 |
| ← → / Home / End | 인물 페이지의 섹션 탭 사이 전환 |
| Tab / Shift + Tab | 대화상자 안에서 포커스 이동(대화상자 밖으로 나가지 않음) |
