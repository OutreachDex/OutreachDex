# 快速开始

OutreachDex 帮你和每一个重要的人建立一对一的联系：了解对方、准备有针对性的消息、由你审核后发送，并持续跟进。所有资料都保存在你电脑上的**工作区文件夹**里，第一个工作区会自动为你创建。

## 第一次使用

1. **你的工作区**：第一次打开时，OutreachDex 会在 **文稿 → OutreachDex** 自动创建一个工作区（空白模板）并打开，可以直接开始用。想用别的模板或文件夹，点左上角工作区名称 → 新建工作区… 或打开工作区…。可选模板：
   - **空白**：通用阶段，适合任何一对一联系。
   - **专家外联**：调研、首次联系和跟进学者或行业专家。
   - **产品用户关系**：了解产品用户的目标和反馈，跟进问题处理。
2. **添加联系人**：在「人」页点「新建联系人」，或用「导入」从 CSV / 表格导入名单（见[导入联系人](11-import.md)）。
3. **连接邮箱**（可选）：在「设置 → 邮箱连接」添加收信（IMAP）和发信（SMTP）账号。来信会自动归到对应联系人。
4. **准备 Agent**（可选）：分析和起草使用你本机已登录的 Claude Code 或 Codex。第一次使用请先在终端完成它们的登录。OutreachDex 不自带它们：如果还没安装，Agent 面板和「设置 → 分析助手」会显示安装命令。

## 日常怎么用

- 打开「**今日**」：看谁在等你回复、哪些草稿待审核、哪些人该跟进。
- 按 **⌘ / Ctrl + K** 搜索任何人、名单或草稿，回车直接打开。
- 点进一个人：在人物页查看资料、往来、来源事实，点「让 Agent 了解」，右侧 Agent 会梳理情况；「Agent 起草回复」准备待审核回复。
- 在草稿里修改、**批准**，再选择发件账号**确认发送**。OutreachDex 不会自动发送任何消息。

## 界面分区

| 区域 | 作用 |
|---|---|
| 左侧导航 | 今日、人、名单、邮件、来源、设置 |
| 中间 | 当前页面：名单、人物页、文档 |
| 右侧 Agent | 固定在右边的命令行助手，⌘ / Ctrl+J 显示或隐藏，拖动左边缘调整宽度 |

外观可以在「设置 → 外观」切换浅色 / 深色 / 跟随系统，以及舒适 / 紧凑两种信息密度。

界面语言可以在「设置 → 外观 → 界面语言」切换：中文 / English / 日本語 / 한국어。
