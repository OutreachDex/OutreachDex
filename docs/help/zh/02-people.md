# 人与人物页

## 「人」页

所有联系人显示为一张表格。

- **视图**：全部、待回复（对方回复晚于你上次发出）、待跟进（你发出后超过设定天数还没回复）。
- **搜索与筛选**：按姓名、单位、邮箱搜索；按阶段筛选。
- **键盘**：↑ ↓ 或 J / K 移动，Enter 打开。
- **批量操作**：勾选多人（表头的勾选框可以全选当前列表）后，可以批量改阶段、安排跟进（明天 / 3 天 / 1 周 / 1 个月 / 清除），或导出 CSV。
- **导出**：「导出」把当前列表的全部字段导出为 CSV（带 BOM，Excel 打开不乱码）。
- **表格编辑**：直接在表格编辑器里批量整理联系人、渠道、来源身份和往来数据。

## 人物页

左边是内容，右边是属性和联系渠道。联系渠道除邮箱、主页、X、Instagram、微信外，也可以记录 WhatsApp、TikTok、Facebook / Messenger、LinkedIn 等账号。

| 分区 | 内容 |
|---|---|
| 概览 | 下一步、来源事实、切入点、AI 背景摘要、Agent 记录、注意事项、待处理草稿、最近往来 |
| 草稿 | 这个人的所有草稿，按渠道筛选 |
| 往来记录 | 邮件、记录的资料和反馈、来源事件 |
| 档案 | 这个人的 Markdown 档案，可以直接编辑 |

- **事实和推断分开**：带「资料」「来源」标签的是记录下来的事实；带「AI 推断」标签的是助手的判断，请核实后再使用。
- **切换联系人**：顶栏的 ↑ ↓ 或键盘 K / J 切换上一位 / 下一位，Esc 回到列表。
- **阶段**：在右侧属性里修改。发出消息后会自动变为「已发」类阶段，收到回复后变为「已回复」类阶段。阶段名称可以在工作区配置里修改（见[工作区与配置](10-workspace.md)）。

## 资料：自定义字段

人物页右栏的「资料」列出这个人的所有字段，点一下就能修改，**离开输入框时自动保存**。

- **添加字段**：电话、职位、生日、标签、关系等，都可以点「添加字段」自己加。
  - 类型可选：文本、长文本、数字、日期、链接、是 / 否、单选、多选（标签）。
  - 新字段会加到所有联系人上，保存在工作区的联系人表格里。
- **选项**：单选字段选「＋ 新选项…」可以添加选项；多选字段直接输入，用逗号分隔，新的标签会自动加入选项。
- **助手只读部分字段**：上次联系 / 回复时间、AI 摘要和编号由应用维护，不在这里编辑。
- **变更历史**：右栏底部「变更历史」列出每个字段什么时候从什么改成了什么。

## 合并重复的联系人

同一个人有两条记录时，在保留的那条人物页点「合并…」，选择另一条记录：

- 合并前会列出将迁移的内容：渠道、往来记录、来源身份、草稿、记录的资料，以及会补全的空字段。
- 合并时：
  - 渠道去重；
  - 空字段用另一条补全，已有的值保持不变；
  - 上次联系 / 回复时间取较新的一个；
  - 被合并方的档案正文追加到末尾。
- 被合并的记录会删除，无法撤销（工作区可以用 git 或备份恢复）。已批准的草稿合并后需要重新批准。

## 记录资料和反馈

在人物页点「记录资料 / 反馈」，可以贴入网页摘录、社交动态、用户反馈原话或回访结果，并注明来源。选择「保存并让 Agent 分析」，右侧 Agent 会结合这条记录分析下一步。

只保存链接不会自动抓取网页内容，请贴入原文。
