# 今日

「今日」把需要你处理的事放在一屏，按优先级排列。

| 分组 | 含义 |
|---|---|
| 等你回复 | 对方最近回复了，你还没有回应 |
| 待审核草稿 | 助手或你写好、等你批准或发送的草稿 |
| 到期跟进 | 安排的跟进日到了，或你发出后超过设定天数没有回复（在「设置 → 分析助手 → 跟进提醒」修改天数） |
| 需要你判断 | 数据源里待确认的身份匹配，以及同步失败的来源 |

点任意一行会直接打开对应的人、分区或草稿。统计下方的「同步并汇总」会让右侧 Agent 同步已连接的邮箱和数据源，并按紧迫程度汇总谁有新动态（只汇总，不起草、不发送）。暂停和不再联系阶段的人不会出现在等回复和跟进里。

## 开始使用清单

新工作区的「今日」顶部会显示一份清单：添加联系人、连接邮箱、连接数据源、准备分析助手。完成的项会自动打勾，全部完成或点「不再显示」后隐藏。

## 跟进提醒

每个人可以有一个「下次跟进」日期，在人物页「下一步」下方设置：

- 一键选「明天」「3 天后」「1 周后」，或选一个日期；「清除」取消提醒。
- **发出消息后**（邮件发送或标记已发），会自动安排在「跟进提醒」天数之后。
- **对方回复后**，提醒自动清除，这个人会出现在「等你回复」。
- **收到外出自动回复时**，会按信里写的返回日期（如「11月10日」「November 10」）安排在返回后一天；识别不到日期就安排在一周后。
- **保持联系**：在跟进栏右侧选择频率（每周、每两周、每月、每季度、每半年）。设置后，发出消息时按这个频率安排下次跟进；一直没有安排跟进、而上次往来已经超过这个频率时，也会提醒你。
- 跟进日到了的人会出现在「到期跟进」和「人 → 待跟进」里。
