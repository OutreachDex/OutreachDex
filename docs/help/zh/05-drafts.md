# 草稿、审核与发送

发送一律由你完成：**编辑 → 批准 → 选择账号并确认发送**。

## 编辑和批准

- 在人物页点「写草稿」，或打开助手生成的草稿。
- 可以选择一份**参考稿**并排对照，例如两个助手各写了一版。
- 关闭弹窗或切换页面时，未保存的修改会暂存在本次会话里，草稿上会显示「有暂存修改」。暂存不等于保存；退出应用前会提示。
- 点「保存并批准」后，草稿进入已批准状态。**批准后再修改任何内容，都需要重新批准。**

## 审核时的提示

- **AI 原稿**：助手写的草稿会保留原文。你改过以后，在「参考稿」里选「AI 原稿（修改前）」可以并排对照。
- **可能过期**：对方在草稿生成之后又来信了，草稿上会显示「可能过期」。发送或标记已发前，必须勾选「我已看过最新来信」，后端也会再检查一次。
- **文案检查**：正文下方会提示套话开头、AI 腔词汇、篇幅过长、问题和链接太多、感叹号或破折号过多。只是提示，不会自动修改。
- **未替换的占位符**：比如 `{{name}}`、`[姓名]`，会被直接拦下，不能发送。

## 让助手越来越像你

审核草稿时，点正文下方的「**记住一个写作偏好**」，例如「开头不要寒暄，直接说明来意」「中文不超过 150 字」。

- 偏好保存在工作区的 `preferences.md`；
- 之后的分析、起草、名单批量准备都在 Agent 终端里进行，都会遵循；
- 在「设置 → 写作偏好」可以查看、修改或删除。

## 收件人检查

邮件草稿的收件人必须是这个人的已知邮箱：资料里的邮箱、联系渠道里的邮箱，或已关联来源里的邮箱。写错或 Agent 写了一个对不上的地址时，收件人下方会出现黄色提示，并给出已知邮箱，点一下就能改正。仍要发送到新地址时，发送前会再请你确认一次。

## 发送

- **邮件**：已批准的邮件草稿选择发件账号（SMTP），点「发送邮件」，再在确认框里确认一次。
- **其他渠道**（X、Instagram、微信、WhatsApp、TikTok、Facebook / Messenger、LinkedIn 等）：应用不会代发，也不连接这些平台。点「复制正文」，到对应平台自己发送，再回来点「标记已发」。

发送前，应用会强制检查以下三项，任何一项不通过都不会发送：

1. 收件地址不在「不再联系」名单（工作区 `suppression.txt`）里；
2. 联系人的阶段不是「不再联系」；
3. 来自名单的消息没有超过每日上限。

需要整体停一停时（例如退信变多、要检查发送配置），在「设置 → 分析助手」勾选「**暂停所有发送**」：邮件发送和「标记已发」都会被拒绝，草稿仍可编辑和批准，顶栏会一直显示「已暂停发送」。

如果发送时网络中断，草稿会标记为「请核对发送结果」并锁定，避免重复发送。请到邮箱的已发送里核对。
