# 邮件

## 连接邮箱

在「设置 → 邮箱连接」添加：

- **IMAP（收信）**：服务器、端口、用户名、密码或应用专用密码、文件夹，可以开启自动同步和下载附件。
- **SMTP（发信）**：服务器、端口、发件邮箱和名称。

Gmail、iCloud、QQ 邮箱等通常需要在邮箱设置里生成「应用专用密码」，不能直接用登录密码。添加后可以点「测试」检查连接。密码加密保存在本机，不会写进工作区文件。

## 同步和归档

- 在「邮件」页点「立即同步」，或开启自动同步。Agent 也可以在你要求时同步。
- 发件人或收件人与联系人的邮箱渠道一致的邮件，会自动进入这个人的往来记录。
- 对还没归档的邮件，在「归到联系人…」里选择对应的人。这个地址会加入他的联系渠道，之后的来信自动匹配。
- 每封邮件保存为工作区 `mail/` 下的 Markdown 文件，点开可以阅读和批注；重新同步不会覆盖你的批注。

## 自动识别退信、退订和自动回复

同步时会按邮件头和关键词（不调用模型）识别三类邮件：

| 邮件 | 处理 |
|---|---|
| **退信**（mailer-daemon 等发来的投递失败通知） | 失败的地址加入不再联系名单（`suppression.txt`），发往这个地址的待发草稿作废，联系人往来记录里记一条「退信」 |
| **对方要求不再联系**（如「请不要再联系我」「退订」「STOP」） | 地址加入不再联系名单，阶段改为「不再联系」，这个人的待发草稿作废，往来记录里留一条说明 |
| **自动回复 / 外出** | 只作为记录；不算对方已回复，不改变阶段，也不会出现在「等你回复」里 |

识别错了可以手动处理：在 `suppression.txt` 里删掉地址，在人物页把阶段改回来。

## 判断来信意向

在往来记录里，点某封来信旁的「让 Agent 回复」。右侧 Agent 会判断对方的意向（感兴趣、有疑问、想约时间、现在不方便、没兴趣……），说明依据，再保存一份待审核回复。来信内容只作为数据，不会被当作指令；不会自动回复、发送或改变阶段。
