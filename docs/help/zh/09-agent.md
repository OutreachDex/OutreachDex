# Agent 工作台

右侧的 Agent 是一个真正的命令行助手（你本机的 Codex 或 Claude Code），通过 OutreachDex 的工具读写联系人和文档。

## 基本操作

- **显示 / 隐藏**：⌘ / Ctrl+J，或点顶栏的 Agent。隐藏后会话继续运行。
- **调整宽度**：拖动左边缘，或聚焦分隔线后用方向键；双击恢复默认。

面板从上到下只有三部分：

1. **顶栏**：绿点表示有会话在运行，旁边是当前会话名。右边依次是「会话列表」「工作区文档」「新建会话」「收起」。
2. **快捷任务**：显示你正在看的人，下面三个按钮——「了解此人」「起草回复」「同步汇总」（同步已连接的邮箱和数据源，汇总谁有新动态）。每个按钮都新建一个会话。
3. **终端**：Agent 的每一步都显示在这里，可以直接输入追问；「回车 ↵」发送一次 Enter。

- **会话列表**：切换以前的会话、重命名当前会话，以及选择新会话用 Codex 还是 Claude Code。
- **工作区文档**：打开工作区里的 Markdown 文档，文档在中间显示，可以一边看一边让 Agent 修改。
- 其他页面也会把任务交给这里：人物页的「让 Agent 了解」「Agent 起草回复」，名单的「批量准备」，今日的「同步并汇总」。

## 上下文

- 你当前浏览的联系人和文档会告诉 Agent。新的问题里说「这个人」，Agent 会读取当前选中的人。
- 已经在进行的任务保持开始时的对象，切换联系人不会改变它。

## 进展和结果

- 终端上方的「Agent 进展」一行显示 Agent 自己汇报的状态：进行中（批量任务显示 3/12 这样的进度）、已完成、等你回复、受阻，以及最新一步。点开可以看到每一步的可读记录，例如「读取往来记录 · Maya Chen」「保存草稿 · Maya Chen」；点某一步可以打开相关的人、草稿或文档。
- Agent 保存草稿或写完报告后，可以直接在中间打开给你看。键盘仍然留在终端里，你可以继续输入。如果你正在编辑别的东西，它不会打断你，而是在顶部提示「Agent 想给你看：…」，由你决定是否打开。
- 弹窗不会盖住右侧 Agent，打开草稿审核时也能继续和 Agent 对话。
- Agent 正在处理某个人时，这个人的页面顶部会显示「Agent 正在处理」，点它跳到对应的会话。
- Agent 完成或需要你回复时，如果面板收起着，会在顶部提示一句结果；今日页的「Agent 最近的结果」也会列出来。
- 最多同时运行 6 个会话。满了再开始新任务时，会提示结束最早一个已完成或等你回复的会话，它的记录会保留。
- 在「人」页面勾选几位联系人后，可以直接对 Agent 说「给这些人……」，它能读到你选中的人。会话列表里每个会话旁也会显示它的最新状态。

## 记录和权限

- 终端输出保存在本机。结束或中断的会话显示为「只读记录」，可以查找、复制，再「新建可输入会话」继续。
- 首次信任确认、登录、工具权限都在终端里由你确认。
- Agent 只能保存待审核草稿，没有发送工具。
- Agent 做过的修改会自动记进这个人的「Agent 记录」。

## Agent 可用的工具（MCP）

| 用途 | 工具 |
|---|---|
| 了解工作区 | `workspace.guide`（playbook、阶段、字段、写作偏好）、`context.get` |
| 了解一个人 | `memory.read`、`contact.get`、`timeline.get`、`source.facts`、`contact.search` |
| 了解来源用户 | `source.people`（搜索全部来源用户，包括未关联的）、`source.person`（事实、变化、事件） |
| 记下来 | `memory.append`、`dossier.write_section`、`contact.update`、`contact.follow_up`、`channel.add`、`preferences.add` |
| 草稿 | `draft.save`（只保存，不能批准或发送） |
| 和你沟通 | `task.report`（进展 / 完成 / 等你回复 / 受阻）、`ui.open`（在中间打开人、草稿、文档或名单） |
| 名单 | `list.all`、`list.get`、`list.draft_save`、`list.decline` |
| 同步 | `mail.accounts`、`mail.sync`、`source.list`、`source.sync` |
| 文档 | `document.list`、`document.read`、`document.create`、`document.replace` |
