# 导入联系人

## 从 CSV / TSV 导入

1. 在「人」页点「导入」，选「联系人（CSV / TSV）」，再选择文件。Excel 请先「另存为 CSV UTF-8」。
2. 应用会预览前几行，并根据列名自动对应字段。中英文列名都能识别，例如 姓名 / Name、邮箱 / Email、公司 / Affiliation、备注 / Notes。
3. 在每列上方调整对应字段，或选择「不导入」。必须有一列对应「Name」。
4. 点「导入」。

导入规则：

- 先按**邮箱**、再按**姓名**匹配已有联系人，匹配到就更新非空的字段，否则新建。
- 邮箱、主页、X、Instagram 会同时加入联系渠道。
- WhatsApp、TikTok、Facebook（列名写 Messenger 也可以）、LinkedIn 列只加入联系渠道，不占用联系人字段。
- 「阶段」列的值必须是工作区配置里的阶段名称，否则会被忽略并给出提示。

## 导入 WhatsApp 和 LinkedIn 会话

会话记录来自你自己导出的文件。OutreachDex 不会登录你的 WhatsApp 或 LinkedIn，所以不会给账号带来风险，也不会触发限流。

在「人」页点「导入」，然后选择：

- **WhatsApp 聊天**：在 WhatsApp 里打开一对一聊天，点对方名字，选「导出聊天」→「不含媒体」，然后选择得到的 `.zip`（iPhone）或 `.txt`（Android）。群聊不能导入，请分别导出和每个人的聊天。
- **LinkedIn 消息**：在 LinkedIn 进入 设置 → 数据隐私 →「获取数据副本」，勾选「消息」和「人脉」，然后选择 LinkedIn 发到你邮箱的 `.zip`（最长可能要等一天）。

预览会列出每个一对一会话，以及它会归到哪位联系人：

- 先按联系人渠道里的 WhatsApp 号码或 LinkedIn 主页匹配，再按 LinkedIn 人脉里的邮箱匹配，最后按完全相同的名字匹配。你可以改成别的联系人、新建联系人，或选「不导入」。
- 如果看不出哪个参与者是你，应用会让你选。WhatsApp 导出里如果所有日期都能两种读法（01/02），请选择是日在前还是月在前。

导入会写入：

- 消息按天保存在工作区的 `chats/whatsapp/…` 或 `chats/linkedin/…` 下，每个会话每天一个 Markdown 文件。
- 联系人的时间线每天、每个方向各一条（「WhatsApp: 最后一条消息 (+3 more)」），打开即可看当天全部消息。
- 「上次联系」「上次回复」只会往后推，阶段跟着最后一个发消息的人走；处于已结束或不再联系阶段的人保持原阶段。
- 对方的 WhatsApp 号码或 LinkedIn 主页会加到联系人渠道里，下次导入自动匹配。

同一个聊天或归档可以随时导入更新的导出文件：已经导入过的消息会被识别出来，只会补上新的。

## 命令行导入

```sh
globalcontact import contacts.csv --workspace /path/to/workspace
```

目标工作区不能正在被桌面应用使用。新建工作区时可以加 `--template user-relationships` 等指定模板。

## 在表格中批量整理

「人」页的「表格编辑」会打开联系人表格，可以直接新增行、修改字段，适合批量整理。
