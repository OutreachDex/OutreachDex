# 隐私与安全

- **数据在你手里**：联系人、档案、草稿、邮件、来源事件都保存在你选择的工作区文件夹。OutreachDex 没有云端服务，也不收集使用数据。
- **密码和 token**：邮箱密码、数据源 token 用本机密钥加密，保存在应用数据目录，不会写进工作区文件。
- **AI 助手**：分析使用你本机已登录的 Claude Code / Codex。分析时，助手可以读取工作区资料，相关内容会按照该服务的条款发送给对应的模型提供方。
- **不会自动发送**：助手只能保存待审核草稿。每一次发送都需要你批准，并在确认框里再确认一次。
- **不打扰**：「不再联系」的地址和联系人，任何名单都不会选中，也不能发送。名单消息有每日上限。
- **数据源只读**：只调用后台的只读接口，只保存后台在 manifest 中声明过的属性；必须使用 https。
- **不可信内容**：邮件、网页和来源事件的正文对助手来说只是证据，不会被当作指令执行。
