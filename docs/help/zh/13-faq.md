# 常见问题

**右侧 Agent 无法新建会话，或提示找不到命令行**
请确认本机已经安装并登录 Claude Code 或 Codex（在终端里能正常运行），并在「设置 → 分析助手」里看到「已检测到」。也可以在 Agent 的「会话列表」里换另一个助手。程序装在特殊位置时，可以在「高级」里指定路径。

**邮箱连接失败**
大多数邮箱需要「应用专用密码」，并且要在邮箱设置里开启 IMAP / SMTP。在「设置 → 邮箱连接」点「测试」查看具体原因。需要代理时填写代理 URL。

**来源检查失败**
按检查结果逐项修正后台接口，例如分页没有前进、字段格式不对、缺少 manifest。开发者可以用 `globalcontact source check` 在命令行反复自测。

**同步后有人在「待确认」**
这些人的邮箱和你的联系人一致，但后台没有验证过这个邮箱。请确认是不是同一个人；选「不是」之后不会再提示。

**草稿显示「请核对发送结果」**
发送过程中连接中断，无法确认邮件是否已经发出。请到邮箱的已发送里核对；这份草稿已锁定，避免重复发送。

**发送被拒绝：在不再联系名单中 / 达到每日上限**
这是防止打扰的保护。确实需要联系时，把地址从工作区的 `suppression.txt` 里删掉，或调整 `globalcontact.toml` 的 `[outreach] daily_limit`。

**打开工作区提示已被另一个进程打开**
同一个工作区同时只能被一个窗口或命令行导入使用。请先关闭其他窗口。

**修改了 globalcontact.toml 没有生效**
重新打开工作区。格式有误时会提示具体的错误位置。
