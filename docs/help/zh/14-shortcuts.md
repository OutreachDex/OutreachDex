# 快捷键

| 快捷键 | 作用 |
|---|---|
| ⌘ / Ctrl + K | 全局搜索：人、名单、草稿、页面和常用操作（在终端里不拦截） |
| ⌘ / Ctrl + J | 显示 / 隐藏 Agent（在终端里也可用） |
| ⌘ / Ctrl + S | 保存当前文档或草稿 |
| ⌘ / Ctrl + F | 在 Agent 终端里查找记录 |
| ↑ ↓ / J K | 在「人」列表里移动；Enter 打开 |
| J / K | 在人物页切换下一位 / 上一位 |
| Esc | 关闭弹窗；在人物页回到列表 |
| ← → / Home / End | 在人物页的分区标签之间切换 |
| Tab / Shift + Tab | 在弹窗内切换焦点（不会跳到弹窗外） |
